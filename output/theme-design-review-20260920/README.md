# 战斗地图主题设计确认稿

这两张图只用于美术方向确认，尚未带入 Cocos 游戏。

- `campaign-themes-preview.png`：四种关卡主题。每个主题可以覆盖一组 1–5 关，组内只改变路线，不改变整体风格。
- `modes-themes-preview.png`：副本、竞技场、世界 BOSS、无尽主题。

共同约束：保留现有夜海、灯笼、石砌栈道和圆润 3D 风格；路线位于同一片连续陆地上；中间保留大片连通的可站位区域；站位区域避开道路，不使用固定圆台、不把角色放在怪物路线中间；守护目标放在路线终点，后续单独使用贝壳珍珠方案。

确认后再进行：按确认的主题切分关卡资源、把实际路线数据绘制到地图、接入现有 HUD/技能/自动释放/自由站位，并重新出 Cocos 试玩包。
