# 哥喂龟美术参考图提示词

本轮使用内置 image_gen 工具，未使用 CLI。三组双画面参考板，每组上方战斗、下方主界面。最终版按照用户新增要求移除战斗货币，仅在主界面显示金币。图中 UI 属概念演示，最终名称和排版以设计讨论稿与后续人工 UI 设计为准。

## A 原始生成提示词

Use case: stylized-concept.
Asset type: original game art direction comparison board, TWO complete landscape game screenshots stacked vertically, one battle scene on top and one home screen below, each screenshot at 16:9 aspect ratio, high resolution. Full-frame clean board, small gutter.
Primary request: Concept reference for original 3D chibi turtle tower-defense game named "哥喂龟" with provisional English name "GO AWAY TURTLE". The player protects a luminous tidal pearl in a turtle island sanctuary from cute mischievous ink-sludge critters and crabs. Five friendly turtles are stationary tower units with distinct readable silhouettes: round stone shell frontline guardian, amber spike shell ranged attacker, blue crystal shell mage, leaf shell healer, spiral tide shell controller. Small original turtles with four short legs, expressive simple faces and unique shell architecture. These are turtles, no humanoid martial artists.
Top screenshot: actual playable-looking isometric tactical battle, fixed camera tilted down 55 degrees, winding clearly visible sandy lane from left entrance to right pearl sanctuary, 5 turtle defenders on circular placement pads bordering lane, some small enemies on lane, one chunky crab boss, restrained readable attack effects and targeting area. Turtle and enemy sizes readable, surroundings quieter than gameplay. HUD top shows pearl health 18/20, wave 08/15, currency 240; bottom five turtle portrait cards plus clearly identifiable merge action. Show a small shell-fusion interface cue without obscuring action. Terrain cannot block the road.
Bottom screenshot: matching same world home screen, an inviting 3D sanctuary island, central featured turtle and four companions, pearl lighthouse/home building, visually coherent shell-themed UI. Exact Chinese title "哥喂龟" and small English "GO AWAY TURTLE" upper left, one prominent large "开始冒险" button at right, four quiet bottom navigation labels "龟龟图鉴" "队伍" "培育" "设置". Avoid red notification dots, price tags, gacha purchase buttons. Both screenshots must use SAME art direction and matching turtle character designs.
Constraints: original independently designed characters, environment and UI. No existing game characters, no existing franchise logos, no watermarks, no photoreal humans, no imitation of a named artist or studio. No promise of actual game graphics; this is concept exploration.
Style/medium: premium stylized 3D collectible toy diorama; smooth matte vinyl turtle bodies, ceramic-like shells with broad clean shape changes, soft rounded bevels, lush simplified vegetation, airy warm sunlight and soft ambient occlusion. Palette creamy sand, mint water, teal foliage, apricot accents. Crisp high-quality real-time game render rather than flat illustration. Cute but not babyish, expressive humorous turtle poses. Most commercially accessible and production-feasible visual direction. Board label "A · 潮汐玩具岛".
