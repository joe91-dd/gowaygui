# 岩盾：AHOLO → Blender → 实时三维验收

本轮只处理已经生成的岩盾，作为内部效果样品。没有继续生成另外四只，也没有再次调用计费生成接口。正式商用权限尚未确认；用户拟在效果通过后开通 PRO，届时需核对中国站对应套餐与 API 输出的授权范围。

实时页支持旋转、缩放、前/侧/后视角、战场视角、待机、出场回应、连续攻击、岩石风暴、受击、暂停、慢放和拖动时间轴。眼睑开合、水晶流光和技能粒子在实时页面中运行。模型不依靠一张正面图片冒充立体角色。

## 实际制作内容

1. 保留 AHOLO 原始 GLB、源资产 ZIP 和实际任务记录（3513206）。
2. 在 Blender 中统一尺寸与朝向，让双脚落在同一地面；焊接重复接缝后减面，保留一份高细节网格数据。
3. 调整脸宽与眼周形体；增加曲面虹膜、眼球、眼睑形变及细小眼部反光。
4. 分离黄金皮肤、深色岩石、腹甲、水晶等材质，调整粗糙度、清漆与发光参数。
5. 清理手部与腿部的生成粘连，拆分双臂并补齐隐藏切面；建立 16 根骨骼与最多 4 权重影响的蒙皮。
6. 制作待机、出场、两段近战攻击、施法、受击 5 个动画片段。
7. 实时页增加沿水晶表面移动的发光、拳部命中碎晶、环绕岩块和短促残留粒子。受光和投影来自三维场景，地面实际接收阴影。

## 文件用途有区别

- **GLB** 保存模型、基础 PBR 材质、骨骼、动作片段与眼睑形变，可导入支持 glTF 的引擎。
- **Blender 工程** 还保存灯光、摄像机、材质节点和编辑数据。
- **`review/review.js`** 保存实时水晶着色、技能粒子、动画切换及眼睑播放逻辑。这些动态效果不会因为导出 GLB 就自动变成 Blender 或 Cocos 特效；正式接入还需要移植对应逻辑。
- Lux3D 的离线模型包用于查看原始模型和精修模型、核对源文件及下载；它与包含技能效果的实时验收页用途不同。

## 验收边界

这是一轮完整制作流程的内部验收样品，不能直接称为达到商业三维角色最终标准。

- 外观与原设定仍有差异，尤其是眼睛、脸部细节和局部岩甲轮廓。
- 原始网格来自生成结果；本轮做了局部拆分、修补、减面和蒙皮，**不是专业手工四边形重拓扑的替代品**。
- 手指目前保持握拳形态，不支持独立手指展开和复杂抓握。
- 现有动作范围之外的大角度肩关节、下蹲、极端视角仍需额外检查，不能从几张关键帧推断所有姿势均合格。
- 尚未做真机性能验收、完整 LOD、碰撞体、完整面部表情系统或正式关卡接入。
- 原始模型之前消耗了 20 赠送积分；本轮本地精修没有新增 AHOLO 生成费用。
