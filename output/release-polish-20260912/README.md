# 哥喂龟：2026-09-12 功能与界面修订

试玩：http://127.0.0.1:7460/ 。这是本机服务，不是公网地址；建议横屏或拉宽浏览器。

## 本轮修改

- 主页与登录使用连续的海岛背景。冒险区收纳后不再留下白块，小队头像居中；头像与昵称不再重叠。按钮、导航和角色入口有轻微悬停放大及按压反馈，普通操作按钮降低高度。
- 主页伙伴信息卡进入完整资料，技能卡可再打开技能说明。头像支持五个预设、上传照片及相机预览拍照；裁切到 256×256 并仅写入本机存档。取消、离开页面、关闭资料或延迟授权后都释放相机；不申请麦克风。
- 普通关卡新挑战统一五波，每波有 Boss，最终 Boss 更大、更强。击败 Boss 后才解救并补充未锁定的备战位；空槽、锁定、手动刷新规则继续保留。旧的进行中挑战保留原规则与坐标。
- 缩小战斗顶部 HUD、主动技能栏和备战栏。布阵时可在空白地图区域按住拖动；站位热点跟随投影更新。新地图站位与路线中心至少相隔 1.08 世界单位，道路与站台缩窄以留出间隙；普通关卡仍为九个可选站位、最多五只上阵。
- 射手射程增加，穿甲弹可手选敌人；法师主动改为三段范围暴风雪；潮行主动改为指定区域召唤两只可受伤的小龟。选择范围技能时暂停战斗并显示射程；无效落点不消耗冷却。持续自动释放、单只技能保留手动继续有效。
- 新增六本珍贵通用被动书：散射、迷糊、法术奥义、圣光、通灵、反击风暴。加入抽取、养成、交易显示和存档验证；十二技能规则保留。
- 绿色、蓝色、黄色、橙色、红色对应五档品质边框。技能书使用按效果绘制的独立图标；招募页增加图像展示，六种商城礼包分别显示龟龟、技能书和培养食材。
- 合成结果先保存，泡泡完全遮住伙伴；擦除只显露擦过的区域，点破后先显示造型，再点击伙伴显示资质和技能。局外 A/B/C 留一与局内消耗两只合成一只继续区分。

## 技能初始数值

| 技能 | 本轮数值 |
| --- | --- |
| 潮灵召唤 | 两只小龟，继承 40% 攻击、35% 生命、50% 双抗，持续 12 秒，冷却 24 秒 |
| 海霜风暴 | 半径 1.8，三次 80% 法术伤害，附带减速，冷却 20 秒 |
| 散射 | 普攻额外两个不同目标，各 70% 伤害，可叠加多重攻击 |
| 迷糊 | 自身嘲讽的目标额外减速 30%，持续 3 秒 |
| 法术奥义 | 法术技能伤害 +20%，减速 20%，1% 概率短暂眩晕，有触发间隔 |
| 圣光 | 有效恢复生命时 25% 概率触发，3 秒内减伤及增伤各 10%，触发间隔 6 秒 |
| 通灵 | 召唤物替换为最多两只免伤石头人，存在 5 秒；落地冲击、单体攻击、附近灼烧 |
| 反击风暴 | 受到直接伤害时 20% 触发周围 1–3 次伤害，按生命和双抗计算，间隔 3 秒，禁止递归反击 |

Boss 解救的伙伴在普通波偏向 2–4 技能，末波偏向 3–5 技能并提高资质；“更容易满技能”按对应解救档位上限处理，不直接赠送十二技能极品。
