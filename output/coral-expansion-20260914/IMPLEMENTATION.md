# 珊海远征扩充与战斗表现改进

日期：2026-09-14

## 已实现

- 叶灵的源素材锚定藤蔓：更粗的生长枝条、八组卷叶、浅金绿叶脉、呼吸高光与生长端闪光，主页与战斗共用。
- 底栏「技能」使用与其他入口同尺寸的独立旋涡图标，移除方形技能框造成的风格突兀。
- BOSS 共 48 只：绿色 10、蓝色 10、紫色 8、黄色 8、红色 6、金色 6。新增 42 个独立立绘，保留 6 个已有首领；全部可在普通关卡遇到，并按强度分配副本及无尽的首领波。
- 首领使用六类可反制能力组合：预警破甲重击、霜潮禁锢、远位炮击、近身虹吸、召唤援军、破盾震荡；与重甲、冲刺、恢复特性配合。预警约 1.35 秒，可用控制打断相应蓄力。
- 首领击败后掉落金币、对应资质材料，技能掉落概率按品阶为 8%～23%；同一击杀不会重复发奖，漏过的首领不会解锁击败奖励。
- 成就只保留技能图鉴与 BOSS 图鉴两个入口；已有副本/无尽宝箱仍可从结算入口领取。
- 技能详情增加市场招募/交易及关联 BOSS 来源；BOSS 详情按页显示实际出没地点、必得材料及可能掉落技能。
- 怪物加入交替迈步、上身重心补偿，精英怪增加预警攻击；首领具有独立大小、造型及行动速度。
- 技能表现增加箭雨、海霜旋流/冰晶、岩石冲击、治疗及复活光波、石头人落地冲击、触发型反击反馈；对同时存在的特效数量设上限。
- 伙伴脚底增加按品质着色的流动符文魂环，采用与场景透视一致的椭圆底座；增强并压平接触阴影，让角色层位处于光环上方。
- 地图取消固定站位数字。关卡和副本支持在合法陆地自由摆放，避开道路、障碍、守护物和其他伙伴；支持拖放及点选再点地面，落点即时显示合法性。场上仍最多五只，战中转移成本与冷却保留，换宠不刷新状态。
- 自由位置参与战斗存档、跨波次恢复、副本检查点和校验；旧存档默认位置兼容。
- 修复旧无尽开奖的费用校验：计价单位与当前金币面额一致，单次付费和全部揭晓均可正常存档。

## 验证

- 全量自动检查：497 / 497 通过，包括首领数量/覆盖、摆放状态、存档、掉落幂等、预警打断和迁移金币后的付费揭晓场景。
- Cocos TypeScript 检查通过。
- Cocos Web 构建及打包后核心回归通过，criticalErrors 为空。
- 浏览器以 960×540 视口检查主页、图鉴分组、首领详情、自由拖放、道路拒绝提示、跨刷新位置恢复及椭圆魂环。
- 测试使用独立 7472 来源，不改用户 7464 的存档。
- 已将最终构建接入原 7464 地址；通过用户主页确认第 3 关、1,084,000 金币和 30/30 体力保持一致。

## 验证范围

48 只首领由六种主动能力和三类特性组合，未声称每只拥有完全独立的技能系统。本次没有在实体手机上测量帧率；已有角色继续使用当前美术与连续形变/动作系统。
