# 连续动作与装备发光修订 · 2026-09-14

试玩：http://127.0.0.1:7464/

本次只调整角色呈现，不修改养成规则、战斗数值和存档格式。

## 实现

- 主页五只伙伴和战斗内五职业取消姿势图片的逐张硬切，使用同一张已确认的原画做连续局部变形。脚部保持固定，身体、头部和双臂按蓄势、回应、回位曲线衔接。重复点击不重置正在播放的动作。
- 原来的角色装备特效贴片已移除。新效果在原画坐标内计算，并跟随角色变形；主页和战斗素材分别校准位置。
- 岩盾：根据原水晶的青蓝色面片生成流光与闪耀。
- 叶灵：弓周围有向上运动的绿色叶片，区分弓的前后遮挡。
- 珊歌：转动并扩展原画的水浪纹理，外侧旋涡逐渐伸展和收回。
- 阳光：根据灯内暖色区域亮起，配合渐强渐弱的柔和光晕和小火星。
- 潮行：以法杖宝石为中心蓄光并短暂放射。两套素材的持杖方向不同，分别校准。

这些是基于现有二维原画的连续变形和着色效果，不是完整三维骨骼动画；也没有宣称生成了原画中不存在的新肢体结构。

- TypeScript 检查通过。
