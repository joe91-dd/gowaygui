# 哥喂龟 · 航行动画确认稿

这是独立的视觉确认预览，不是游戏的替换版本。仅在用户确认完成后的动画后，才可以接入游戏。

## 预览

- 本地地址：http://127.0.0.1:7490/
- 同屏对照：http://127.0.0.1:7490/?compare=1
- 启动：`npm run dev -- --host 127.0.0.1 --port 7490 --strictPort`
- 构建：`npm run build`
- 尊重系统减少动态效果设置；如默认停止，点击“播放动画”。

## 本稿内容

采用用户选择的第 1 张航海构图。海水波纹、海雾、帆面、旗帜、船身、伙伴呼吸和武器光效独立处理，不让整幅图和字标一起摇晃。原登录字标作为透明 PNG 直接使用。画内仅保留“正在启航”。

当前采用原画局部位移和光照着色器，属于动态插画，不是角色骨骼动作或真实流体模拟。提供暂停、三档速度、五组特效开关、原图对照和等比例全屏。动态绘制上限 30 帧，暂停时只在配置或尺寸变化时重新绘制，后台不绘制。

第二页为第 3 张衍生的静态关卡海图建议，绘制的按钮和关卡尚未接入游戏。优先建议用于海域/关卡选择；其次用于无尽之海远征路线、通关后的下一站。
