# 怪物与首领整批美术修订

## 范围
保留 59 种怪物，48 个普通首领和 5 个世界首领。没有调用 AHOLO 或付费生成。源模型及现有 CC0 来源记录保留。

## 制作
- 按原始材质颜色恢复眼部、皮肤、金属的语义，修复灰白眼睛，部分角色增加虹膜、瞳孔、高光与眉形。
- 重绘海岛配色，烘焙细微色差与接触阴影；依体型添加护甲、海玻璃和装备。
- 首领使用独立变体和与技能关联的钳甲、炮口、法器、背甲。更正部分首领名字以匹配真实模型，存档 ID、掉落、品质及战斗数值不变。
- 合并不透明部件，单模型最多两种材质；保留原骨骼和连续动作。
- 图鉴从相同模型离线渲染，统一取景、大小、光照和卡片底色。
- 六类首领技能区分效果，预警半径与逻辑半径一致，取消常驻大光圈。

## 文件
- production：可编辑 Blender、GLB、FBX、贴图、图鉴图与来源清单。
- before / before-assets：修改前的代码与被替换资产。
- plan.json：112 个造型的映射。
- finish.py / install.py：可重复的制作与安装流程。

## 质量边界
这轮是现有免费模型的风格统一、结构补充与实装修订，仍保留原底模的低多边形特征；不能据此声称达到了逐只手工精雕的商业角色标准。人物英雄的精细眼皮和逐指绑定不在本轮改动范围。
