## 本次实现

- 首关使用已批准战斗原画延伸的无人物场景，真实战斗路线与九处路外站位映射到图中。原有第一关战斗快照继续使用旧坐标；重新开始的第一关使用新场景坐标。
- 五类伙伴接入动作图集，攻击前摇、出手与恢复由战斗事件驱动，弹道随真实目标移动；支持治疗、暴风雪、召唤、受击及死亡反馈。普通蟹、变羊及通灵石人使用配套图集。其他关卡沿用各自地图结构，并共用新伙伴动作与技能图标。
- 45个技能使用技能符号，无实体书本：30个黄色通用、10个红色珍贵通用、5个金色职业主动。详情、学习、招募、交易及战斗共用图标映射。
- 主页“调整”编辑五只默认首发，保存后回主页，不启动挑战。首发顺序持久保存；返回直接回主页。首发不足五只库存时允许全部上阵。进行中的战斗独立保留。
- 新技能可从新版招募与技能池获得，支持学习、合成继承和存档恢复，保留旧版出生随机序列。
