# 玩法增量 · 浏览器实际操作记录

环境：Cocos Web Mobile 构建、本机浏览器、896 × 414 横屏视口。画面沿用已有美术，新多路地图为功能几何布局。此记录只描述实际操作；自动领域测试及数值模拟另附报告。

## 已实际检查

- 主页功能入口与金币显示；冒险入口把关卡、无尽、副本、竞技场分开。关卡总数显示五十；新档无尽显示“通关第2关开启”。
- 商城包含龟龟招募、技能书招募、金币礼包三页。礼包页六种商品的价格和每日二十次余量可见；基础龟包详情显示54%/30%/13%/3%概率及72,000金币售价。
- localhost 独立测试档初始300,000金币，购买基础包后得到三技能泡泡龟。刷新后仍显示相同三技能结果，关闭结果回家钱包为228,000，没有重复扣费或重新随机。
- 三副本入口可分别选择；进入碎礁洞穴后为玩家加四个AI，每人备战五只、场上一只。
- 站位选择页显示十二个位置，当前位置突出显示、队友占用位置禁用。选择空闲六号位后，自己的龟移动到该位，场上仍为五只。
- 点击出发后备战栏自动收起；右下显示本人主动技能位置与一键释放，未学主动的龟显示说明。
- 1X切换为2X正常。第一波西入口、第二波东入口、第三波起东西两路同时进攻，入口提示与实际出怪相符；AI进行站位支援。
- 暂停菜单提供继续、保存返回与结束挑战。浏览器错误/警告日志检查未发现运行错误。

## 发现并修复

- 副本入口的旧“五个位置”说明改为五人、十二个共享站位；移除旧无尽波数难度类比。
- 战斗时AI换位导致整个操作栏重建，有打断点击的风险。改为局部刷新占位标记，新增真实界面控制器回归：按下开关后让AI换位，再松开，按钮仍有效且成功关闭自动技能。
- 最新构建实机复查：刷新后从主页继续已保存副本，进入第五波；一键释放从“已开启”切换为“已关闭”，再次点击恢复“已开启”，均有画面确认。最新运行错误与警告日志为空。
