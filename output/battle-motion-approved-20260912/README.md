# 已选定战斗方向与动作样段

用户确认图：`approved-battle.png`，对应 exec-27029905。另一张简化版本不作为标准。

预览：http://localhost:7462/#project/motion-study

12 秒有限动作样段，支持播放、暂停、进度拖动。1.1–3.6 秒：射手两次拉弓、箭矢命中与扣血；4.5–6.6 秒：岩盾收身防御与局部护盾；6.8–10.2 秒：法师蓄力、冰霜命中、敌人短时停止动作并减速。阳光、潮行为静态角色。地形和 UI 保留选定图，不是可操作游戏。

场景拆分与姿势图使用内置 imagegen，提示词见 prompts.json。actors-key.png 在浏览器运行时通过色键材质透明显示；原素材不被修改。动态效果与角色帧由 Canvas、GSAP 绘制，HyperFrames 负责时间轴和预览。

现有游戏、玩法基线和试玩链接未被替换。此目录仅为美术动作评审素材；没有把有限姿势切换描述为完整骨骼动画。

当前环境缺少 FFmpeg/FFprobe，因此没有导出 MP4；使用在线本地预览查看动作。预览服务使用工作区内状态目录 .state。
