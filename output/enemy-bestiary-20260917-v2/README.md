用户确认的制作范围：10 普通 BOSS＋4 高级 BOSS＋5 基础小怪＋1 精英。普通 BOSS 与精英后续均有蓝、紫、橙、红、金五档变异。当前交付的是 20 个基础形态，不把换色或世界放大版计作新物种。精英基底采用蓝色壳缘，后续变异优先改变壳缘、甲片、凸起和体型，保留脸部识别特征。

用户所说“三色图”按此前对话的“三视图”执行：正面、侧面、背面。三视图图中可能使用 FRONT / SIDE / BACK，页面及文件清单使用中文角色名。

## 美术与建模约束

- BOSS 比第一轮更有力量感：较小而锐利的眼睛、厚眉甲、下颌、胸肩和背部轮廓；仍保持五龟设定的圆润海岛奇幻风格。
- 高级 BOSS 必须明显强于普通 BOSS；世界形态沿用高级 BOSS 基础模型。
- 图鉴是三视图的角色身份参考。同一角色的颜色、面部、甲壳、角、尾巴和主要附件应对应，不能在背面凭空换造型。
- 三视图采用中性展示姿态、尽量接近正交相机；艺术设定图尚不等于已校准工程投影，也不证明模型有合格拓扑和骨骼。
- 蟹类目标结构：六条行走腿＋两只钳臂；两只章鱼类目标为八腕；四足类保持四足。隐藏部位须在建模时再核对。
- 生成概念中的细小甲片和纹理可以烘焙；决定剪影的角、晶簇、螺壳、冠饰和大甲片应保留体积。
- 不用强光、烟雾或漂浮粒子遮挡建模结构。
- 保守按 20 个角色资产安排，蟹类如验证可共用基础网格可降低至约 18 个基础网格；不提前承诺一定复用成功。

## 动作检查安排（尚未制作）

所有角色需待机、移动、攻击、受击、死亡。另需：
- 普通 BOSS：与对应技能相符的蓄力／施法／重击。
- 苍潮龙王：破甲蓄力重击；幽渊墨皇：虹吸施法；熔礁魔君：破盾重击；晶脊岩王：冻结施法。
- 快跑蟹：冲刺前摇；铁壳蟹：架盾；雾泡怪：冻结蓄力；吐墨螺：远程吐射和治疗；搬壳大蟹：重击蓄力。
- 模型与动作之后必须在游戏内常用镜头检查脚底、触腕和钳子穿插，远近距离识别度以及同屏怪群性能。

本阶段只制作二维图鉴与三视图，供用户确认。尚未调用 Aholo 生成模型，也没有修改游戏配置。图鉴与三视图都经用户确认后，再报价并按授权预算做一个代表角色的模型、材质、骨骼、动作与实机验证，随后再批量。
