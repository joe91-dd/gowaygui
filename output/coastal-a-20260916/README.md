# 海雾灵焰 A · 怪物与首领美术更新

以用户确认的 A 方向为准，对现有 59 种普通怪物、48 个关卡首领、5 个世界首领统一处理。保留猫狗、软泥等现有物种，不更改战斗数值、技能规则、掉落或存档。

## 实际资产

- 以原 CC0 模型为基础，圆润有机轮廓、修整眼部层次、制作贴身护甲与暖铜装饰；鲨类取消突兀大尖角，并从原图集的眼睛区域定位制作眼白、虹膜、瞳孔与眉骨。
- 皮肤、护甲、金属、海玻璃区分粗糙度，输出底色、切线法线和打包 PBR 材质贴图。普通怪物 512 px、首领 768 px、世界首领 1024 px。
- 每个模型最多两个绘制材质，交付 FBX、GLB、带贴图的 Blender 源文件及实际模型渲染图。沿用原骨骼动作。
- 图鉴改为一页三张大卡，奶油白石台、浅海蓝背景、接触阴影；卡片与详情均使用同一份实装模型的渲染。

## 妖气

翠绿 → 湛蓝 → 明黄 → 朱红 → 香槟金。原紫色首领品阶保留，与蓝色首领共用蓝系妖气；黄色与金色在色相和流光亮度上区分。所有世界首领采用金色妖气。

战斗效果是贴地上升、有深度遮挡的三维弯曲灵焰，不遮住脸部。每只普通怪物 3 缕、首领 5 缕，合并成一个网格；五档材质共用，避免为每颗粒子单独更新或创建节点。死亡后停止、对象池复用后恢复。图鉴使用同色、同方向的流动焰线与稀疏光点。

## 许可和限制

所有模型来源与 CC0 许可记录保存在每个模型的 manifest.json 及游戏资源内的 license-and-source.json。没有调用付费模型生成服务。A 确认图只用于方向参考，预览页展示的是实际三维模型。

这次是现有模型的统一风格改造，未把概念图中的全新解剖结构逐一精雕成同等高模；模型仍保留原素材的基本比例。没有以此宣称达到商业大作的角色精雕质量。本机软件渲染性能需以实际试玩为准。

## 可复现流程

finish.py → install.py → Cocos build-config.coastal-a.json → build_review.py。finish.py 可跳过已完成的模型，鲨类独立面部版本可增量重建。verify_exports.py 检查 FBX 动作及有限包围盒；game/tests/fauna-finish.test.cjs 检查全资源及图鉴；fauna-aura.test.cjs 检查强度颜色映射。
