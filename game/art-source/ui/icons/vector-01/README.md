## 制作规范

所有几何从零编写，没有读取、描摹、抠边、重绘或转换此前生成的 PNG。A 参考仅用于项目配色和圆润玩具方向。没有下载其他游戏或素材站图像；图标中没有品牌、文字、数字、红十字或额外货币形状。

统一左上柔光；主体轮廓 5–6 SVG 单位，内部装饰通常 3–4 单位，符号通常 4 单位。渐变与高光都在真实主体轮廓内，不使用投影、模糊、发光或外围透明底色。四种药共用瓶形，但颜色和符号双重区分。

## 验证结果

1. 已实际打开透明 PNG 图集，并逐枚查看小尺寸深浅底审查图。没有出现旧位图候选的白色纸边、伪棋盘或彩色外沿碎点。
2. 八枚独立 PNG 均为 256 × 256、4 通道；主体内部存在真正 alpha 255，轮廓外为 alpha 0，只有正常轮廓抗锯齿为半透明。
3. 每枚外侧 24 像素安全区所有像素 alpha 均为 0。最终图集 4 × 2 的每个 cell 外侧 24 像素也逐像素检查，非零计数为 **0**。
4. 图集无裁切、重叠、非整数切片坐标。没有用代码清理旧 raster 的 alpha 来获得此结果。
5. `review-64-48.png` 是新 SVG 的实际小尺寸渲染，不是把大图截图缩小后宣称检查；正式 Cocos 纹理过滤仍需主代理运行时确认。

## 重现与修改

渲染依赖当前机器已捆绑的 **sharp 0.35.4 / librsvg 2.62.91**，未安装额外软件。可通过 `GOWAYGUI_NODE_MODULES` 指向另一处已有 Node 模块目录。

```powershell
& 'C:/Users/Administrator/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe' 'game/art-source/ui/icons/vector-01/render-icons.cjs'
```

修改单枚 SVG 后运行上面的渲染脚本即可。`make-icons.cjs` 保存了最初的源码制造过程，默认拒绝覆盖已有 SVG；仅在明确要用制造脚本重新生成整组源码时使用 `--force`。不要用它覆盖尚未同步回制造脚本的手工修改。

审查图中的说明文字使用系统字体，图标 SVG 本身没有可见文字或字体依赖。当前机器的 Fontconfig 会输出缓存目录不可写提示，但两次渲染均以 0 退出，图标像素验证与实际审查图显示通过。
