## 尺寸、透明与切片

- 工具实际输出 **1774 × 887**，没有遵守提示词的 2048 × 1024。不能将 512 × 512 或等分整数格坐标直接套到这张图。
- 当前候选为 RGBA，alpha 为 0 的像素占 **87.19%**。没有 RGB 棋盘背景。
- 存在 19,012 个 alpha 1–15 的像素，其中包含边缘抗锯齿和零散背景碎点。大部分实体内部 alpha 是 252–254，而非完全 255。不能宣称“所有非物体像素全透明”或“所有物体内部完全不透明”。
- `layout.json` 提供八个 **320 × 320** 的矩形，按 alpha ≥ 16 的主体边界居中，避免依赖生成器不精确的等分中心。该阈值仅用于测量，**没有用于修改 PNG**。
- 八个矩形最外侧 8 像素的最大 alpha 为 0 或 1，主体周边留白为 57–90 像素。切片不交叠、不切掉主体。逻辑顺序仍为 4 列 × 2 行。
- 坐标原点为 **PNG 左上角**。使用前应按当前 Cocos SpriteFrame API 确认坐标约定；无需真的裁出八张图。SpriteFrame 原尺寸 320 × 320，offset 0、pivot 0.5、rotated false。
