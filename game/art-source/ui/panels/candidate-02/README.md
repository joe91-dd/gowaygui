# 海岛九宫格面板 c02

在 c01 原创 SVG 几何上补齐现有小按钮的精确圆角：16、19、20、21.5。原六种圆角、前三列和前六行位置保持不变。可编辑源与渲染工具位于本目录；没有下载或采用外部美术。

图集为 512×1536 RGBA8，共30帧，未压缩约3 MiB，比 c01增加1 MiB。运行时仍共用一张纹理，四层分别为阴影、填充、外金线、内奶油细线。参数以 layout.json 为准，装饰尺寸为 2*(w+4) × 2*(h+4)、缩放0.5，父布局和点击区域不变。

review-compact.png 是本轮新增四种圆角的原轮廓与切片离线对照；根任务已实际打开检查。所有30格通过白色RGBA、透明间隔和源SVG逐像素检查。原18格还须由 finalize-c02.cjs 对 c01 做逐字节一致性核对。Fontconfig 缓存不可写没有阻止已有字体渲染；两条生成脚本均退出0。

离线图不能证明 Cocos 中无接缝、按钮可点击或性能通过，仍需要新构建后实际检查。本轮扩展是既有面板的渲染优化，不代表全部界面美术已经验收。
