# 泡泡龟 c01 静态样板

已在首领 Blender 明确退出、根代理确认调度后，用一次串行 Blender 进程完成可编辑源与正面/三分之四两张真实渲染。进程已正常退出 0；两张图均已实际查看。现在提交根代理审图，未做运行导出或推广。

`game/art-source/build_bubble_turtle_candidate01.py` 复用自有 c12b 头/短肢/眼睛/十骨基础，以及冻结的水晶 c02 `objmesh`、`tube`、数值图集函数。基础源和 helper 已按已知 SHA256 复制到 `inputs/`，没有执行旧生成器的顶层场景构建代码。

本次造型是连续奶油白弧壳、沿同一实壳曲面贴合的蓝色螺旋、十四段圆润蓝白壳缘；一眉稍高、单侧半笑，不改变已审眼球/眼开口和头/肢体网格。没有单独竖盾或图板、服装、武器、人类身体或透明排序需求。材质为同系列不透明玩具质感，颜色和粗糙度全量从自有参数生成，没有修改已有 PNG。

主壳宽归一化为 2.03，主弧壳顶 1.72 模型单位、螺旋 2.1 圈及最大约 .024 的浅实几何浮起；以原 A 材质/比例和 A4 第五只五官为视觉依据。只输出完整编辑源与正面、三分之四两张 800×680、32 samples、CPU 2 预览供审图，不导出运行 LOD/FBX，不推广。

原骨架六动作仅作为可编辑基础保留，未当作泡泡龟专属六动作的完成或验收证据。泡泡弹体/控制圈留给后续视图层；不改变 `bubble` 或 `bubbleRing` 的现行玩法规则。

## 实看判断

`render-front.png` 和 `render-three-quarter.png` 均已实看。蓝螺旋确实有弧面体积、在正面和斜视都可辨认，头/眼/短肢维持当前四龟系列比例。但本轮仍有三个明确差距，未宣称审美通过：

- 白壳大面积连续留白，偏光滑蛋壳/头盔感，比 A4 的紧凑蓝白分瓣螺壳更单调。
- 蓝纹的圆鼓截面更像凸起软线，A4 更接近与壳相接的蓝白环带；当前内端也略像弯钩。
- 原眼开口保持得清楚，但高低眉与半笑的差异仍偏温和，还不够 A4 的调皮男孩感。

本轮仅提交这一个样板，不自动追加改型、完整动画渲染或运行导出。后续是否针对上述差距修正由根代理实际审图决定。

## 源文件与范围核对

- `bubble-turtle.blend`：47,886 源三角、78 个独立编辑网格和十骨基础，两张自有参数图集已打包；这是编辑源，未声称满足运行三角预算。
- `bubble-turtle-review-scene.blend`：同系列灯光、世界和相机的摄影棚源。
- `inputs/provenance.json`：原 c12b 编辑源与自有 helper 的来源及 SHA256。
- `atlas-parameters.json` 和 `textures/`：固定数值/种子、完整颜色与粗糙度生成结果；没有渲染 PNG 输入。
- `candidate-manifest.json`：全部保护文件、源/图集哈希、几何范围和预览状态。

生成过程中逐项核对 59 个共享网格的顶点、面、UV 和权重保持；新增壳体部件闭合，所有权重归一化，十骨基础保持；已冻结四龟的 source/runtime 文件哈希未变。没有启动 Cocos 或改 .meta、view、core、共享 docs。没有执行泡泡专属动作回导/半帧穿插/运行材质或性能检查。
