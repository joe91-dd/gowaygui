# 泡泡龟 c02 — 独立静态造型候选

本轮只调整 c01 的壳与轻微表情差异。主线程已实际查看两图，批准此造型进入独立运行候选制作；本目录高模与两图冻结，不代表最终 Cocos 验收。

## 本轮范围

- 主壳参数高度从 1.28 降至 1.13（下降 11.72%），主壳总宽仍为 2.03。蓝带随连续壳面重新贴合。
- 蓝螺旋最大半宽从 0.069 增至 0.1035，最大凸起从 0.024 降至 0.012；中央平缓、边缘圆顺，内端由同一网格的圆弧端帽收尾。
- 壳缘仍为 14 段，拓宽上下跨度，保留连续壳面做底；弧长覆盖率 0.992，避免悬浮椭圆贴片与宽黑缝。
- 仅略加强高低眉与单侧嘴角。原有头、眼开口、短吻、肢体网格、UV、权重及比例通过签名比对保持不变。
- 图集由原自有数值函数全量生成，无栅格输入；配色、种子、UV 与粗糙度参数沿用 c01，贴图打包在可编辑源内。

## 文件与复现

- `../../build_bubble_turtle_candidate02.py`：本轮独立参数化生成脚本。
- `bubble-turtle.blend`：可编辑模型、原 10 骨架和基础动作，保存于摄影棚创建前。
- `bubble-turtle-review-scene.blend`：同系列摄影棚、相机与模型。
- `render-front.png`、`render-three-quarter.png`：800 × 680，Cycles 32 samples、固定 2 CPU 线程。
- `inputs/`：冻结的自有基础源、图集/网格函数及来源；`textures/` 为全量生成图集。
- `candidate-manifest.json`：源/贴图/脚本 SHA、参数、网格统计与受保护文件哈希。

从仓库根目录执行：

```powershell
& 'tmp/tools/blender-4.5.13-windows-x64/blender.exe' --background -t 2 --python-exit-code 1 --python 'game/art-source/build_bubble_turtle_candidate02.py'
```

脚本对 c01 全目录、c01 原脚本及已冻结四龟资源执行前后 SHA 检查，不改写这些来源。

## 验证边界

本轮静态源为 48,026 三角、78 个可编辑网格、10 骨。封闭壳、归一化权重、59 个共享身体/眼部签名及 147 份保护文件 SHA 均通过。两张图已实际打开，并重新打开 c01 对比：蓝纹更宽更平、内端圆钝，壳缘形成连续分瓣。详见 `manual-review.json`。

高模中的六动作来自石头龟基础，保留供编辑，未在此高模完成泡泡自身动作或 Cocos 验证。后续 LOD、独立六动作和回导检查放入 `runtime-candidate/`，不改写本高模与已审图片，也不进入 c03 造型修改。
