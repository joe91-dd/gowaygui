## 实看结论与剩余风险

六张 PNG 均已真实打开。近景的脸、眼开口、琥珀虹膜、嘴角和总体比例保持；攻击与受击关键帧未见新的前脸穿壳。首页原生大小的两个样板差异很轻，五官仍可辨认。

近景可以看见成本：**顶壳几块甲片的倒角比原版更硬、部分平甲面明暗边界更明显，前掌底缘出现轻微多边折线，少量圆趾较扁。** 这是本候选的审美风险，尚未证明适合作为近景统一 LOD。若未来决定试接，宜先单只、固定镜头 A/B 核对实际 Cocos 法线与高光，再决定使用距离；不要直接批量简化其余四只。骨骼变换没有改变，但减少腿部顶点后，原本细密的轮廓会在特定角度或抬脚时更容易显出折面。

**只有几何统计，没有 FPS 结论。** 材质数、透明度策略、draw call 数和动画逻辑未做运行调整；当前实际瓶颈还可能在界面、提交、阴影、像素填充或 CPU。
