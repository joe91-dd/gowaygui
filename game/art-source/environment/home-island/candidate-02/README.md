# 首页海岛 c02：限定一轮收尾候选

本候选已完成可编辑建模、FBX 回导、真实脚底支撑检查和五龟两视渲染，等待根代理图审。没有晋升 resources，没有修改 core / views，没有启动 Cocos。源 c01 的 31 个文件（含预览、日志和 blend 备份）完整原字节保留，见上一层 `first-round-freeze.json`。

本轮只做三个美术调整：

1. 保留原五点、Y=.16 支撑面和庭院中部，外沿改为不规则铺石边，并用真实草地起伏贴合铺石外侧，减少原连续直薄边的板状感。
2. 原珍珠位置不变，补浅下贝壳、圆润唇边及低托圈。下贝中心上表面 Y=2.544 与珍珠最低 Y=2.54 有 .004 接触；没有用发光掩盖悬空。
3. 仅在铺石外沿和屋旁补 8 簇 .22–.42 高的草，完整边界避开五龟脚底与门口通道。

同时针对首领海湾发现的开放曲面倒面风险，新增草地、铺石和下贝上表面的显式朝上约束；实际 FBX 回导的 1,408 个绿色面全部朝上。首页 c01 原草地也已只读确认朝上，本轮没有把它误报为旧缺陷。

## 实际审图结果与剩余边界

已实际查看 `render-home-overview.png` 和 `render-house-detail.png`：

- 全景中五龟脸、门口、左栈桥可辨；泡泡占据原预留后右位置，没有增加或移动站位。
- 珍珠下托座在全景和近景都可见；门与角色脸没有被新增下贝遮挡。
- 铺石外沿被分成大小和角度有变化的收边石，并由草地贴合。中部仍保持较大平整展示面，这是五龟支撑约束的一部分。
- 新低草位于外缘，未发现脚底穿插或门口遮挡。近景为屋旁检查视角，左侧晶龟部分出画，不作为完整阵容主画面。

离线支撑与两张静态图不能替代 Cocos 的真实 UI、动画全过程、资源加载/销毁和帧率检查。尤其根任务当前实际机能数据仍不足以宣称性能达标，本候选没有做此宣称。没有继续调色或开展第二轮美术迭代。

## 文件用途

- `home-island.blend`：845 个可编辑环境部件，不含角色、海面、相机、灯光。
- `home-island.fbx`：环境与空 anchor；不含角色或骨架。
- `home-island-review-scene.blend`：环境、离线海面、灯光和相机。
- `home-island-scale-review.blend`：五龟的离线实例，仅用于尺度与构图检查，禁止作为环境 FBX 导出源。
- `author_home_candidate.py` / `home_composition.py` / `build_home_island.py`：原创模块组成与完整生成脚本。
- `verify_home_island.py` / `round-trip-and-support.json`：实际回导、脚底和上表面检查。
- `render_home_views.py` / `render-report.json`：五龟来源 SHA、两视实际参数和输出 SHA。
- `provenance.json` / `source-freeze.json`：来源、检查边界与冻结文件记录。

共用材质名为 `Island_atlas`、`Warm_pearl_and_lamps`；网格组为 `Ground`、`Landmarks_and_nature`、`Pearl_and_lamps`。全部沿用本项目自制海岛几何和图集方法，没有下载其他游戏、品牌或库存美术素材。
