# 叶子龟 c02 三视候选

本轮仅精修叶壳，等待根代理审图；没有晋升运行资源或启动 Cocos。已实际查看正面、三分之四与侧面，并与 A4 和 c01 对照。相同灯光和相机下，c02 的叶片厚度、短胖轮廓和下缘错位比 c01 明确，但上层仍有圆厚片感，叶尖与覆盖方向尚不如 A4 清楚，不能自行判定美术验收通过。

## 本轮实际变化

仍保留 47 片闭合叶网格，把单叶缩短、增加横截面厚度、轻微卷边/抬尖；上下层错开，底缘叶片的位置、长度和转角有变化。内层壳弧略降以补偿叶片新增体积，主壳总高由 c01 的 1.537459 m 到本轮 1.561706 m，头宽/主壳宽仍是 0.595923。绿色/黄绿色只调整了四个叶片图集色块，其他颜色不变。

叶层深浅由实际几何和间距形成，没有修改摄影棚、材质粗糙度或用噪点掩盖。粗糙度 PNG 与 c01 的 SHA 完全相同。

两朵自然白花直接取自 c01 自有网格快照，顶点、面、UV 和权重保持一致；保留暖眼、脸、眉、嘴、身体、腿、骨架和六动作。没有服装、人类身体或穿戴饰品。

## 三视实看

- 正面：叶体厚度和底缘错位提升；上部仍有圆垫/圆片感，尖端方向不够鲜明。
- 三分之四：下层部分黄绿叶尖和叶间阴影可读；上层部分尖端仍被邻叶中部的隆起吸收。
- 侧面：短胖叶形与底缘尖端更明显，白花可见；上部仍偏连续圆壳上的厚片。

如继续迭代，优先检查相邻叶尖与叶腹的上下覆盖关系，不继续增加高光来表现厚度。是否进行下一轮由根代理审查决定，本任务在提交三视后暂停造型工作。
