# 叶子龟 c03 叶形原型

本轮先制作三片叠叶小样，实际查看确认叶尖/中脉/覆盖关系后，用同一叶形参数铺满 47 片叶壳，只渲染一张完整三分之四图。没有导出 FBX/GLB、运行 LOD 或六动作，也没有晋升或启动 Cocos。现在提交根代理审查，不继续自行改型。

## 实看结果

`leaf-stack-preview.png` 的三片小样可辨认圆润短尖、浅中脉和上下叠置关系，上片尖端显露在下片叶腹上方。

`render-three-quarter.png` 的完整壳已经更明确地读作层叠叶片；叶尖、中轴起伏与生长方向比 c02 清楚。剩余问题是层间黑缝偏宽，分层轮廓仍明显，比 A4 更像逐层展开的叶簇。没有依靠增加白描边、粗高光或改灯光来制造层次。是否收紧层间距离由根代理审查决定。

本轮降低叶壳内部支撑弧面，用从外到内递增的径向层高，保证露出的叶尖高于下一层叶腹；单叶本身采用较薄的微拱截面、圆短尖和实际浅中脉起伏。仍保留 47 片，脸、暖眼、肢体和两朵小白花不改。
