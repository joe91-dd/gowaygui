# 叶子龟 c01 三视原型

本目录是独立、未晋升的第一版 3D 候选，供根代理审查。完整阅读并实看了 `output/art/A4-五龟三男两女角色参考.png`、`output/A4角色图提示词.md` 和原 `A-潮汐玩具岛.png`。已明确发现叶壳层次不够，不应视为美术验收通过；下一步等审，不自行追加造型或接入 Cocos。

## 造型与编辑源

保留已批准系列的 c12b 头部、圆短肢体和十骨骼基础，以暖琥珀眼、柔弯眉的轻微不对称、短微笑区分叶子龟的温和好奇性格。没有人类身体、衣物或穿戴饰品。叶壳为 47 片闭合叶状网格分层覆盖，底层浅绿、上层深浅绿色错排，保留 A4 的两朵极小自然白花。

独立脚本 `game/art-source/build_leaf_turtle_candidate01.py` 在本目录内重建源、导出、图集和摄影棚。固定输入为 `inputs/authored-c12b-foundation.blend`，来自项目自有石龟 c12b 源；SHA256 为 `53f828584edcc3d93c1b28a01883fe768db106a1fd44f27b5f95d729482a4ac3`，见 `inputs/provenance.json`。初次执行的眉线越出面部表面时检查立即报错；已把眉峰收回原头部可贴合区域，再次完整生成成功，头部没有改形。

- `leaf-turtle.blend`：可编辑叶片、身体、脸、花、10 骨骼和六动作，颜色与粗糙度图集由脚本打包。
- `leaf-turtle-review-scene.blend`：导出 LOD 摄影棚。
- `export/leaf-turtle.fbx` 与两张 `leaf-*.png`：候选导出，没有写入 resources。
- `leaf-turtle.glb`：仅保留为源检查替代格式。
- `atlas-parameters.json`：原创数值调色板、固定种子 **81207**、解析眼部和叶脉 UV 方程，无栅格图片输入。

叶片不是图板：闭合的卷曲叶体、横截面和隆起中脊构成实际几何，细叶脉色差用自有数学方程生成。两处小白花也是闭合自有网格。没有从其他游戏提取模型、贴图或骨骼。

## 当前实看结论

三图均为原生 Blender 3D 渲染，800×680、32 samples、固定 2 CPU 线程，未做栅格后期。

- 正面：暖色大眼、短脸和短肢体保留系列识别；叶界太弱，整体接近一顶连续绿色圆壳。
- 三分之四：同样缺少 A4 叶片的厚度与错落阴影，底缘叶片偏大且顺排；小白花可见但不抢主体。
- 侧面：圆壳、叶片、小白花与完整四肢尾部可见；再次确认层次偏浅，没有发现贴图缺失。

主要待修是单叶截面的厚度、边缘弧度/轻微上翘、上下层留出的距离及排布。不能仅增加纹理噪点或色差来掩盖叶层体积不足。脸和头身先保持，是否做下一轮由根代理审查决定。
