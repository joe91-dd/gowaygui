# 音乐备选 · 商用来源说明

本目录的 `alternatives/` 是《哥喂龟》项目专属的确定性合成音乐备选。旋律、和声、节奏、音色参数与混音由 `compose_alternatives.py` 生成，没有采样第三方录音、SoundFont、现成旋律或网络素材，也没有调用需要付费或限制商业用途的生成服务。

项目可以免费将这些 WAV/OGG 候选用于商业游戏、试玩包、宣传视频和后续发行版本。保留本说明和脚本即可追溯来源；正式上线前仍建议把最终选中的曲目登记到项目素材台账。

## 候选用途

| 文件 | 游戏位置 | 气质 |
|---|---|---|
| `alt_home_sunlit` | 主页、海岛待机 | 明亮、温暖、轻海岛感 |
| `alt_battle_tide` | 普通关卡 | 轻快推进、持续战斗不压对白 |
| `alt_boss_abyss` | 普通 BOSS | 低沉、紧张、压迫感 |
| `alt_world_boss` | 世界首领 | 仪式感、巨大感、慢速推进 |
| `alt_endless_drive` | 无尽模式 | 更快、更有循环驱动力 |
| `alt_reveal_starlight` | 抽奖、合成揭晓、稀有奖励 | 短促、明亮、星光感 |

这些是试听备选，尚未替换当前运行时音乐；确认后再接入对应的 `bgm_*` 或提示音事件。
