2026-09-09。当前依据为用户 [核心玩法试玩增量目标](../output/核心玩法试玩增量目标-2026-09-09.md)，原目标中不冲突的要求继续保留。本文记录原稿已经确定什么、哪些旧规则冲突，以及哪些配置尚未得到实施授权；不把候选数值称为已经冻结的正式经济。

## 已确定且必须复用

- Cocos 3.8.8 同一工程、同一战斗系统、现有五龟与七类敌人；无尽不另造演示战斗。
- 金币是唯一货币。现有普通关每完成一波 8 金币、通关额外 20、首通另 100、广告只翻基础金币；不把这张普通表自动延展为无尽收益。
- 局内新龟一至三技能，正常局内成长最多补到四技能；十二技能全部真实生效，额外数量由合成产生。现有职业兼容、合成概率和三资质加成长不改变。
- 合成与收录分开且可恢复。不收录 C 时永久 A/B 保留；确认收录 C 后，实际来源才转为历史。旧稿“30 波后不能收录”的例外不能盖过此规则。
- 已有四种培养药、100/300 金币费用与培养上限保留，不恢复已经弃用的潮露结晶。
- 技能书局外使用，学习前可放弃；确认后随机覆盖一项现有技能，数量不变。已拥有或职业不兼容时不消耗；不加入技能锁、广告救援或免费回滚。
- 原始 `Desktop/gowaygui.docx` 写明无尽无需体力、开局选择五只、产出金币和培养用品、波次成就抽取技能书；没有精确掉率表。较新的 v0.5 只明确普通关体力规则，未另冻结无尽入场规则。

## 待定项的处理

已向用户发出一次澄清：由助手明确补齐并冻结首次试玩配置、先给用户确认具体表，或由用户提供另一份已定数值表。**当前尚无回复，不把等待时间视为授权。** 未确定前，不接入自创的正式奖励、技能书供给、额外收费或无尽难度表。

待明确的项目包括无尽解锁与入场、奖励有效范围与里程碑、重复及首次产出、药品与技能书来源/概率、招募与合成频率、敌人倍率、首领周期、实体上限。既定普通关经济、培养价格和合成概率保持原值。

## 可独立实施的技能书事务

正式替换规则可先实现成生产领域函数，再由 `GameService.transact` 同时扣书、写入新技能和持久化结果。无效请求不推进随机数；重复操作编号不重抽、不重复扣书。旧存档缺少库存字段可解释为没有技能书，但旧结算缺少书奖励收据时不得按新表补算奖励。

局外沿用 `ensureHome`：没有进行中对局或已经处于结算才可学习。结算后原 run 保留是正常情况，不把打书后的新技能回写旧战斗、旧 run 个体或已固定合成结果。旧已收录个体再次收录必须返回最新永久收藏；先给来源 A 打书后再收录旧 C，则最新 A 转历史，C 的既定结果不变，消耗的书不退款。比较界面须能说明这一成本。
