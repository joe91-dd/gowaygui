# 本地声音试听页

打开 `output/audio-review.html` 即可逐项试听现有三首音乐和十八个音效。它引用 `../game/assets/resources/audio/`，无需服务器、账号或 Cocos，不读取游戏存档或音量设置。移动该页面时须保留相对目录。

方便单独交付的文件是 `output/audio-review-pack.zip`：完整解压后打开其中的 `audio-review.html`，旁边 `audio/` 已包含全部 21 个原字节文件。打包清单见 `output/audio-review-assets.json`。最终验收包可以直接纳入此 ZIP，或者保留其中的页面与音频目录结构。

页面提供音乐逐首播放/停止、每首循环、最后五秒循环接点、播放进度、音乐和音效独立音量、四组中文用途名以及全部停止。没有自动播放；切换曲目停止旧音乐，切换音效停止旧音效。音乐与一个音效允许同时播放作对照。切到后台、关闭或离开页面会停止并释放音频；返回后需再次点击。

请用户先用手机外放，再用耳机对照，每首音乐连续听两轮。反馈格式：**项目名 / 设备 / 页面音乐与音效音量 / 时间点 / 希望调整的感觉**。重点听音色是否刺耳或单薄、循环是否突兀、重复是否疲劳、音效是否被音乐盖住。页面默认 55% / 65% 只是试听起点，不是游戏混音最终值。

此次读取全部 Ogg/WAV 的真实采样率、声道、帧数、时长与 Cocos audio-clip 元数据；21 个 SHA-256 与已有制作检查报告完全一致，总原始大小 6,086,274 字节。ZIP 内再次核对全部音频哈希；没有改动原音频、谱面、MIDI、分轨或来源文件。

既有响度、峰值、循环接缝等技术结果见 `AUDIO_REVIEW.md`。页面实际脚本由 `output/audio-review-source/review.test.cjs` 执行 stub 测试，**7/7 通过、0 失败**，覆盖无自动播放、异步切歌竞争、独立音量、循环接点、全部停止、后台/离开取消、播放失败后再次点击恢复，以及所有引用路径。

**实际浏览器交互尚未验收。** 本轮 CUA 浏览器入口返回 `No browser is available`，因此没有声称页面已在实际浏览器播放或完成人耳试听。脚本测试不能替代音频设备、浏览器本地文件播放策略、主观听感和实际 Cocos 密集战斗混音验收。
