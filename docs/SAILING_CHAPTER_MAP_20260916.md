# 航行动画与关卡海图接入

用户先确认第 1 张航行动画接入游戏，随后确认第 3 张海图也接入。现有游戏规则、存档结构、关卡解锁和选队/开战流程不变。

## 航行等待界面

`IslandArrival` 继续作为启动、首页和战场共用的一个过渡层。图片与雾素材逐字节使用用户确认稿，原生 `sailing-arrival.effect` 保留其局部动画参数，原登录字标不再浮动。资源到齐后才设置材质，失败可保留静态原画，销毁时释放图片、纹理、帧、材质和 Effect 引用。

## 第 3 张海图

- 接入主界面的「关卡」入口，而非额外打开一个演示页面。
- `ChapterMap.ts` 为每个海域呈现五座岛屿，覆盖已有 50 关 / 10 海域；章节名称和全局关卡编号动态显示。
- 关卡状态来自 `unlockedLevel` 和 `cleared`；禁止点击未解锁关卡，已通关可重玩。
- 当前小船停在当前进度对应的泊位；回看已完成海域时停在最后一个可挑战岛屿。减少动态设置禁用船的浮动，销毁页面停止 Tween。
- 点击岛屿及「继续冒险 / 再次挑战」调用原有 `chooseTeam`，不绕过阵容选择和体力规则。左右海域分页不写进度。
- 背景根据确认稿去除烘焙的文字、假状态、按钮和固定小船，再由真实可交互组件叠加；不是把一张静态截图当成界面。
- 暂不替换无尽、副本、竞技场或通关结算；本次海图落在最适配的关卡选择位置。
