# 战斗三维表现适配器

`game/assets/scripts/view/BattleWorld.ts` 仅消费战斗状态与事件，不进行攻击判定、计时结算、掉落、随机、存档或音频播放。血量、死亡、控制与位置均以领域状态为准；弹道是短暂的视觉提示，不延迟或改变结算。

## 接入

```ts
const world = new BattleWorld(parent, sceneCamera, pipelineMaterial);
world.setLevel(run.levelId); // 每次新进入一局调用一次，相同关卡重开也调用。
world.syncRunUnits(Object.values(run.units)); // 布阵、替补、合成后以及波间归位。
world.update(battle, events, dt); // 每帧调用；events 由上层消费核心事件后传入。
world.slotWorld(slot); // 返回含父节点变换的站位世界坐标，供上层投影和点击。
world.setEnvironment(authoredPrefab); // 正式环境准备好后替换临时环境。
world.destroy(); // 离开战斗释放实例、缓存网格、材质及资源引用。
```

传入场景中的有效标准材质。所有程序形体复制该材质并设置 `mainColor` 与 `roughness`；不以错误的内置 effect 名称构建材质。正式石头龟保留 Prefab 原材质和贴图。

相机位置由上层拥有，适配器只用它设置血条朝向。横屏 1280×720 的初始参考位置为 `(0,15,18)`，朝向 `(0,0.2,0)`，透视视场角 42°。实际 UI 安全区与手机窗口仍需运行检查。战斗根节点使用 DEFAULT 层。临时地面宽 22、深 12，路线与五站位读取当前 `LEVELS`，原点与核心模拟一致。

`syncRunUnits` 适用于准备及波间阶段，它会清除上一波敌人和特效，并使龟归位、恢复站立和满血显示。战斗进行中不要每帧调用它，持续调用 `update`。备用、已消耗的龟不显示在战场。准备页的交互与备用列表仍由上层 UI 负责。

## 动作与可读性

- 石头龟使用 `StoneTurtle_Rig|idle / attack / skill / hit / rest`。普攻与施法面向目标；动画播完回待机。当前样板没有死亡专用动作，倒下用休息动作和下沉表达，**不能算正式死亡动画验收通过**。
- 临时角色使用轻微呼吸、攻击前探、受击抖动与倒伏；下一波恢复站位。敌人沿核心路线移动与转向，败退后短暂缩小再隐藏。
- 普攻依职业区分短打、暖色弹道、蓝色法术弹道、绿色治疗弹道。穿甲弹、水晶炮用较粗短光束；守住、大治疗、泡泡圈用不同颜色与尺寸的地面环。无全屏闪光和镜头震动。
- 当前生命条左侧对齐，护盾为独立浅蓝细条；护盾环和头顶控制环来自实际状态。满血、死亡、断点恢复均按当前状态同步。
- 同一波事件按递增 ID 去重。暂停恢复只播放最近 0.4 秒内的事件，单帧至多 120 条；历史伤害不反复刷屏。新的波次、重开或时间回退会重置事件游标。事件缺失不会影响战斗显示的当前生命、位置和结局。

## 资源与性能边界

网格只建五种，颜色材质按色值缓存；角色仅在加入、消耗或换职业时创建。特效池固定 48 个节点，满池时较重要的技能可替换旧的小受击，低优先级效果不会挤掉高优先级技能。敌人节点保留到该波结束后一次清理，已死敌人不会每帧重新创建。异步模型加载检查销毁状态；退出关卡会释放自持资源引用。父节点、相机和传入材质的所有权属于调用者。
