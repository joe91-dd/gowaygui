# 《哥喂龟》Art / UI V2 界面迁移预览

这是保留玩法基线后的独立界面迁移版本。主页面与关键功能已接入新视觉，**整套正式美术尚未完成**。

## 打开试玩

开发电脑访问 `http://127.0.0.1:7458/`。解压独立预览包后，也可双击 `Start-Art-V2.cmd` 启动。

原玩法基线继续使用 `http://127.0.0.1:7457/`。两个地址使用独立的浏览器存档；本轮没有自动迁移、覆盖或重置原进度。包内不含测试存档。

## 已接入的内容

- 登录：海岛背景、游戏 Logo、本地开始入口，以及说明、隐私和设置入口。
- 主页：海岛建筑布局，七个建筑入口、中央无尽入口、底部四种模式、金币和体力、改名与折叠聊天。
- 角色展示：五种站立角色立绘、头像与品质框；角色 ID、属性、玩家自定义名称保持不变。
- 我的龟龟：12 格分页、职业筛选、锁定筛选、品质排序、右侧个体资料与培养入口。
- 商城：六种礼包图、真实价格与当日剩余次数；概率和购买确认进入二级页面。
- 无尽：独立入口、最高波次、主要产出、规则入口、原解锁条件。
- 竞技场：独立海岛竞技场背景，自己的排名、防守队伍、真实本地 AI 对手和挑战入口。
- 合成：主副位与预览、亲本汇入的短过渡、单个五彩泡泡的实际擦除/轻点揭晓、A/B/C 留一。结果仍在揭晓前保存，动画不参与抽取。
- 战斗：普通关卡、无尽和挑战模式的技能图标使用统一素材；原一键释放开关、目标选择与速度功能继续使用原逻辑。
- 全局：金色主按钮、蓝色选中态、深蓝资源条、木质建筑标牌、米白信息面板。

图片只构成可见素材层。金币、库存、数量、按钮命中与页面跳转都是实际游戏界面，不是把参考截图直接铺满屏幕。

## 保持不变的规则

唯一货币仍是金币。体力上限仍按原配置。礼包价格和概率读取现有经济配置；图中的钻石、示意价格、120 体力、赛季段位等没有新增到玩法中。

合成继续使用已培养面板、60% 主龟/40% 副龟外形、局外 A/B/C 留一。没有新增混合造型，也没有改变抽取或消费时机。

好友、交易、租赁和匹配仍是原有本地 AI 测试实现。登录页没有伪装成已接通真实微信登录。

## 尚未完成

1. 正式站立 3D 模型、骨骼动画与材质尚未达到 04 角色参考质量。试制源文件单独保留，没有替换运行中的旧模型。
2. 战斗仍使用原来的真实 3D 地形与角色。05 参考中的水面、瀑布、植被层次以及五类完整技能特效还需要进一步制作。
3. 主页和详情中的新角色当前是透明立绘，不是已经完成的可旋转 3D 角色。部分角色身材比例仍需向正式设定校准。
4. 交易、好友、详细培养等次级页面已使用统一组件，仍需逐页做最终版式精修。材料单品图标还有旧药瓶图，需要换成对应海鲜图。
5. 目前以本机横屏 1280×720 检查。微信/抖音真机适配、内存与帧率验收不包含在这次界面预览完成范围内。

因此本包可用于检查界面布局、入口和操作，不能视为“全部正式美术已完成”的发布包。
