# 《哥喂龟》V0.6.1 核心玩法试玩

本轮用于判断新版核心循环，完成后等待试玩反馈。沿用当前五龟、海岛、敌人、UI 和音频；保留五关，加入无尽资源循环。真实广告、微信/抖音适配、联网榜单、PVP、租借及发行精修仍在后续计划中。

## 直接开始

本机已有服务运行时，在同一浏览器打开 **http://127.0.0.1:7457/**。保留同一个地址和浏览器即可继续当前存档；不要为了更新版本清除存档。`?qa=1` 只增加验收信息，正式试玩可去掉。横屏体验更合适。

重启电脑后，可在工程根目录运行 README 中的 `game/tools/build-serve.mjs`；无需重新构建。Cocos 工程仍是 `game`，不需要现在安装微信或抖音工具。

## 建议试玩顺序

1. **先打一关。** “开始冒险”选择关卡；最多五只收藏龟直接上场，也可取消全部选择，再把随机备战龟拖上场。五个备战槽允许出现同职业的不同个体。
2. **看、锁、换。** 点击备战头像查看全部技能、资质、成长与品质；锁定免费。五个场上伙伴及其站位卡都可以直接拖动换位。备战拖到场上会交换，换下者回到腾出的备战槽并自动锁定；也可把场上龟拖入空备战槽或与该槽伙伴交换。同一波重新上场保留血量、冷却和一次性技能状态。单纯换位不删除收藏本体。
3. **合成备战龟。** 可把一只备战龟拖到另一只备战龟上，在确认页查看本次各技能数量概率；也可继续用“合成备战龟”按钮。确认后 A+B 消耗，固定得到 C。涉及已收录本体时会单独警告：选择仍要合成，将永久消耗参与的收藏 A/B；即使本局失败也不会返还。锁定的收藏本体须先回海岛解锁。新龟默认锁定，可手动解锁。点击泡泡只戳破少量，按住移动逐层擦开，也可直接揭晓。操作方式不影响结果。
4. **开始下一波。** 出战栏在开局和波间自动显示，点击“守住海岛/开始下一波”自动收起。战斗中可点击右上“出战栏”手动展开、收起；也可直接拖动战场伙伴换位。每个非末波结束后：锁定保留，未锁定刷新，空槽补充。末波直接结算，不再补新龟。可以随时切换 1X/2X。
5. **整理通关所得。** 成功带回最终场上及备战中的有效新龟；已合成、刷新或放弃的个体不会带回，换下但仍留在备战槽的新龟可以带回。永久原件不会复制。收藏最多 50；满仓新龟留在“待带回”，整理或明确放弃后再开新局。旧档已经超过 50 的资产保留。
6. **局外合成与改名。** “培养工坊 → 局外合成”选择收藏 A、B，生成并揭晓 C 后，必须从 A/B/C 留一，另两只消耗；不能取消后保住双亲反复重抽。“我的龟龟 → 详情 → 管理伙伴”可以改名、锁定和整理。
7. **打无尽、养好龟、再挑战。** 通关第二张关卡“潮汐小径”后可免费进入无尽；选择最多五龟。每五波几张资源卡自动换位，随机获得一份，无需手选；可以直接揭晓。每十波另有阶段奖励。无尽允许换位和放入备战，但不刷新龟或提供局内合成。失败或主动结束保留合法取得的永久资源。结算可查看全部奖励和最高波次。

技能书与资质培养从收藏详情操作。学习会消耗一本书、随机覆盖一项已有技能，技能数量不增加；结果先保存，再擦泡泡。不同职业只能学习兼容的技能，已有技能不能重复学习。当前原型没有商业购买入口；“模拟广告”只测试奖励流程。

## 保存和恢复

战斗中“暂停 → 保存并回到海岛”保留本局。直接刷新后从首页“继续冒险”恢复；恢复战斗先暂停，点击继续。局内合成会恢复固定新龟；未完成的局外三选一或技能书揭晓会优先显示，不能靠重启重抽。

局内失败或主动结束不带回新龟；未参与局内合成的永久原件保留，已确认消耗的本体不返还。无尽资源按已经完成的波次及领取记录结算；每五波需先揭晓随机结果再继续或结束。候选和获奖位置均先保存，不能刷新换奖。阶段技能书礼包自动打开，实际书计入结算总数，不会再重复发一次礼包。

浏览器更换、端口更换、`127.0.0.1` 改为 `localhost` 都会使用另一份站点存储。没有账号云同步。旧的进行中冒险保留原规则直至结束，新开局才使用 V0.6；旧历史数据保留，新版不再写入历史。

## 本轮请重点判断

每波有没有想看新龟的期待；锁定是否值得；换下能否形成取舍；合成差结果是否过于挫败；通关带回是否满足；局外留一是否过狠；无尽奖励是否让你愿意再打一波；养龟后是否能感到变强；泡泡是否让你想继续擦。

V0.6.1 提高 1～8 技能的合成获得感，9～12 技能单项概率保留；重复技能及职业限制仍会缩小实际技能池。已保存的待揭晓结果不重抽。配置与完整书权重见 [首轮配置](V06_CONFIG.md)，本轮修改见 [V0.6.1 更新说明](V061_CHANGES.md)。品质是综合参考，颜色不额外提高战力或概率。这些仍是测试值，未当作最终平衡。
