# 本地单机存档与永久来源

代码位置：`game/assets/scripts/core/game.ts`、`save.ts`、`platform/localSession.ts`。这是一套本地测试存档，不能直接作为正式经济、排行榜或反作弊依据。

一次操作先克隆旧状态，再改变克隆、验证全部不变量，最后将完整 JSON 写入主键；主键成功写入之后才替换内存。上一次成功状态保留为备份。失败不会先扣金币再漏写结果。每次操作带唯一编号，成功结果记入操作表；重复提交同一编号不会重复发奖、收录或抽样。普通战斗进度使用短检查点，正式合成与收录立即写入。

合成事件和新龟在擦泡泡前一并落盘。跳过动画只改变揭晓状态，不运行随机数。合成输入的本局个体标记为已消耗，永久档案暂不变。确认收录时才把本局个体携带的全部当前永久来源转入历史，并将后代来源更新为自己。这样未收录 C 合成 E 时追溯 A/B，已收录 C 合成 E 时只追溯 C。已锁定来源可以参加局内试合，但收录前必须解锁。局内学得新技能也产生待收录个体，不静默覆盖原档案。

主存档损坏时可读取上一次完整备份，并提示恢复状态；主存档与备份都损坏时停止写入并保留资料，不自动开新档。校验和只发现意外损坏，不是防作弊。浏览器入口必须先获取 `navigator.locks` 的本地游戏独占会话；第二页面不能进入可写游戏。单纯“读版本，再写 localStorage”不是跨页面原子比较，因此不能省略会话层。编辑器或将来的宿主需提供自己的单写者约束。

教学仅第一次进入免体力；之后每次进入消耗五体力，包括未通关重试。避免通过不断放弃免费教学刷取永久金币。普通关基础金币为每完成一波八金币加通关二十金币，十波一百；首通另外一百，不参与模拟翻倍。初始测试赠送五只二技能龟、三百金币、三类资质材料各二和成长材料一；这些是此单机章节的配置起点，不是未来商业发行承诺。

培养攻击、生命、防御每次花一份对应材料和一百金币，提升一点，最多额外十点且总值不超过一百；成长花一份成长材料和三百金币，提升 0.01，最多额外 0.05 且总值不超过 1.10。培养增量不遗传。每关首次通关额外赠送一份材料，具体奖励在结算前明示。

技能书库存为可选的 `skillBooks` 字段；旧档缺失表示零本，不补发历史奖励。只能在没有进行中对局或结算后学习。确认时同一事务随机覆盖一项现有技能、扣除一本对应技能书并写入学习收据；数量仍为原有的一至十二项，不重抽三资质或成长，也不另收未在原稿确定的金币费用。已经拥有、职业不兼容、库存不足或进行中对局均拒绝，且不推进随机数。取消确认不调用学习事务，同一确认编号重试沿用已经保存的结果。

结算后学习只改变永久收藏，不回写上局个体、战斗快照或固定合成结果。已收录个体再次查看/收录使用最新永久档案；旧操作收据可以返回旧答复，但不会覆盖最新技能。若先给来源 A 学习，再收录上局已经生成的 C，最新 A 转入历史，C 保持原结果，已用技能书不退款。界面在学习确认时提醒重新比较。

2026-09-09 技能书领域、事务和界面规则已接入，**正常来源与掉率仍待确认，尚不能据此声称玩家已可正常获得技能书**。相关用例见 `game/tests/skill-books.test.cjs`、`skill-books-service.test.cjs` 与 `menu-readability.test.cjs`；测试库存仅属于独立内存夹具，未改用户存档。跨标签独占、实际书产出和完整浏览器循环须在统一版本验收。
