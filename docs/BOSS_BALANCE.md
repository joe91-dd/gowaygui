# 巨钳来袭数值迭代记录

2026-09-08。最终仅修改 `game/assets/scripts/core/data.ts` 中巨钳来袭的关卡配置与首领生成倍率；教学、三普通关、职业、技能、合成和经济单价均未修改。

## 最终配置

- 十二波；常规敌人在十八秒内生成；每次波间按五秒基础准备计入时长。
- 合成窗口为第四、第八、第十波；本关难度倍率 1.12。
- 巨钳蟹在最后一波第十八秒生成，生命 2400、攻击 72、护甲与法抗各 20。
- 保留每第三次攻击震击、半血召唤、控制减免及漏过扣核心十点。
- 常规通关金币为十二波 × 8 + 20 = 116；首次通关另加 100。波数减少使本关单次基础收入由 132 降至 116，没有另加补偿或调整其他经济规则。

五秒是自动模拟的基础操作预算，实际界面仍应让玩家自行准备；不能强制在五秒后结束阅读或合成。关卡目标为六至八分钟，最终最慢新档样本还留有 33.85 秒额外操作空间。

## 测量方法

使用真实 `GameService`、`SaveRepository` 和固定步长战斗。八个种子为 731、913、2027、4093、6553、9173、12037、19391。每个种子从五只两技能、三项资质 76、成长 1.00 的新档开始，连续完成教学和三普通关，再进入首领关。首波只有射手，每次波间最多招募一只，局内等级与新增技能由服务产生。每关收录真实获得的技能成长；没有直接把五只成型龟放进首波。

标准阵位依次为射手、肉盾、法师、治疗、控制。每波第 2.375 秒持久化并重建服务，将整个后续战斗状态与未中断轨迹比较；结算与重复命令也经过服务。

成长档是明确隔离的四至六技能构筑假设，表示后续合成可追求的合理组合，不能理解成首次通关必定获得。天生资质仍为 76；培养只花真实首通收入与材料，共花 1100 金币。首波依然只有一只，按规则逐波加入，未注入金币或高级资质。

“实际击杀”要求首领生命归零；核心尚存但首领漏过只记为关卡规则上的胜利。以下两者分开统计。时长均为全部实际战斗秒数加每次波间基础准备，没有倍速，也未把模拟运算耗时当成游戏时长。
