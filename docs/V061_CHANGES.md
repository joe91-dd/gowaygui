# 《哥喂龟》V0.6.1 试玩修改

本轮落实用户试玩后的五项反馈，继续已有工程和美术。可回退的修改前版本为 `8b788c2`；上一版试玩包保留。

## 五项变化

1. **合成概率。** 调整 1～8 技能的分布，使低中技能阶段更容易保住数量或有所提升。9～12 技能的可达单项概率保持；职业兼容、去重后的双亲技能池、高资质与高成长规则保持。技能池足够时，1+1 出2技能为65%，8+8 出8技能为49.2%，12技能仍0.05%。全部档位与条件见 [概率表](V06_CONFIG.md)。已生成的待揭晓 C 保留原结果。
2. **拖动换位与备战回收。** 五个站位卡和战场上的龟都支持直接拖动交换。备战拖上场会把原占位者放回腾出的备战槽，并自动锁定；也支持场上龟拖入空槽或与槽中龟交换。满五槽不会删除伙伴。同一波下场再回来保留血量、冷却、攻击进度和一次性技能使用状态，不能反复换位恢复满血。
3. **拖动合成与本体风险。** 备战龟拖到另一备战龟上，先弹确认页，展示 A/B 和真实概率。涉及已收录本体时显示用户指定提醒：“建议回家再合，战斗中合成有损失本体的风险”。用户已进一步明确：警告后仍确认即 A+B=C，A/B 消失。因此确认后参与的永久本体也被消耗，新 C 仍需本局通关带回；失败不返还本体。取消不消耗，收藏锁定时不能合，写盘失败回滚，重启和重复回调不重复消耗。
4. **无尽自动抽奖。** 每五波展示五张资源卡，自动换位后随机获得一份，无手动选择。候选与中奖位置均先持久化，再播放约2.6秒演出；“直接揭晓”、刷新和前后台切换不能改变结果。每十波原阶段奖励继续发放。原候选类型和书池权重保留；由于不再择优手选，实际所得书的频率需结合新反馈判断。
5. **战斗与出战栏。** 开局和波间自动展开出战栏，开始战斗自动收起，给海岛战场更多空间。战斗中可手动展开或收起，并可直接拖动3D伙伴换位、点选主动技能。波次结束后再次展开。无尽的备战只用于调整已有队伍，不刷新伙伴。

## 试玩与存档

已有本机服务运行时刷新同一浏览器的 `http://127.0.0.1:7457/` 即可。独立试玩包解压后运行 `Start-Playtest.cmd`；不要直接双击 `web/index.html`。保留同一地址、端口与浏览器，不清空存档。当前使用的运行协议仍兼容0.6存档；旧局已经消耗、刷新或淘汰的记录不会凭空恢复，本次更新后换下才执行返回备战。旧的未领奖五选一节点会固定生成一个随机中奖位置，再按新流程揭晓。

建议依次试：两站位互拖 → 备战换上再换回 → 两只新备战互拖合成 → 已收录本体警告并取消 → 开战收栏与波间展开 → 无尽第五波自动开奖。完整操作见 [试玩说明](V06_PLAY_GUIDE.md)。
