# 岩盾 / 珊歌 / 礁甲蟹：三维动作验收

本次是独立的三维技术与动作样板，尚未通过最终美术验收。原有试玩仍在 7473，原有角色、关卡资源和玩家存档未替换。新场景使用 Cocos 实时渲染，可从前后方向检查几何遮挡，不能用静态渲染图代替运行验收。

## 使用

打开 `http://127.0.0.1:7475/?review=3d`。

- 点选角色，再点「转身 90°」「转身 180°」「普攻」。
- 「近看」「镜头」用于检查侧面、背面和武器挂点；「¼ 速慢放」用于检查动作过渡。
- 拖到草地会转身行走，拖到另一位伙伴处会交换位置。道路、岸外、守护物和操作栏遮挡区域不能放置。
- 「开始战斗」运行独立的真实战斗核心；岩石风暴为自身周围攻击，海霜风暴需要点选射程内有敌人的区域。无合法目标不消耗技能冷却。
- 「动作展示」重置演示。「返回现有试玩」回到 7473。

## 源文件和重建

源脚本：`game/art-source/sculpted-review/build_review.py`。各角色目录提供可编辑 `.blend`、交换用 `.glb` 和模型统计。运行 FBX 位于 `game/assets/resources/models-sculpted/`，没有覆盖旧角色模型。

```powershell
& 'tmp/tools/blender-4.5.13-windows-x64/blender.exe' --background --threads 2 --python game/art-source/sculpted-review/build_review.py -- stone crystal crab
& 'tmp/tools/blender-4.5.13-windows-x64/blender.exe' --background --threads 2 --python game/art-source/sculpted-review/verify_exports.py
./game/tools/build-web.ps1 -ConfigName build-config.sculpted-review.json
```

Blender 来源和校验记录沿用 `docs/ART_PIPELINE.md`。本次几何、权重、关键帧、程序材质和空间特效由项目制作，没有导入第三方模型或效果包。

## 验证与明确限制

独立 Blender 进程重新导入 FBX，检查所有顶点权重归一、最多两根骨骼影响、骨骼父子关系，以及九段动画实际驱动网格变形。结果写入 `output/sculpted-review-20260915/FBX独立回导验证.json`。

本轮针对性回归 32 项通过，包括原首页生命周期、独立入口不触碰账户和存档、可摆放区域、真实战斗伤害和主动/专精触发。实际 Cocos 页面已观察到出怪、转向、击败敌人、漏怪扣除守护值，修正挂点后未出现控制台错误。已有 Cocos 构建通过；最后的挂点尺寸修正同步修改源代码与独立构建中的同名模块，精确替换和哈希记录保存在 `output/sculpted-review-20260915/anchor-scale-hotfix.json`。没有修改引擎代码。

内置预览操作检查曾出现一次输入超时，重新载入后恢复并完成实战检查。尚未完成真机帧率验收；桌面预览的操作结果不能代替手机性能结论。

独立入口随后跳过了旧版界面图集与角色图片的预加载；原游戏入口仍沿用原加载流程。源代码与独立构建同步修正，记录在 `output/sculpted-review-20260915/review-preload-hotfix.json`。修正后重新通过 32 项针对性检查，并重新确认场景载入成功。实际页面截图保存在 `output/sculpted-review-20260915/实际运行截图.png`。

回导检查证明动画数据有效，不代表造型、脚部锁定、面部表演和性能达到商业验收标准。现在的模型为可修改候选，不能称作已复刻确认原画；全角色、全部怪物、手机 GPU 性能预算和最终材质仍需后续批量制作、设备实测与美术验收。样板中的两人战斗参数只为动作检查服务，不修改正式关卡平衡。

后续应先在同一相机下确认角色轮廓、体积、面部特征、盔甲与布料材质，再精修动作的重心转移、落脚锁定、击打接触和施法节奏。确定单组品质标准后，再扩展其余角色与怪物。
