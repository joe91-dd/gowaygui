# 三维样板第二轮：模型、落脚与场景精修

体验地址：`http://127.0.0.1:7475/?review=3d`。这仍是可操作的品质候选，尚未达到原画复刻或商业成品验收。原有 7473 试玩和玩家存档不在本轮替换范围。

## 本轮实际修改

- 珊歌增加闭合袍服网格、蓝色宽领、包边与扣件，正面能读出法师衣装轮廓。
- 模型增加短距离接触遮蔽数据，减少眼窝、石甲拼缝和衣领的平涂感。Cocos 材质分别处理皮肤、石甲、布料、金属、水晶的粗糙度与高光。
- 岩盾、珊歌增加双腿 IK 控制，并将解算后的骨骼姿态烘焙进 FBX。待机、攻击、施法、受击和入场时保留脚底位置，躯干单独转移重心；行走步幅与实际移动速度一起调整。
- 增加实体眼睑及随眼睑运动的闭合弧线；独立回导 FBX 渲染睁眼、闭眼特写，修正闭合时缺少眼缝的盖片感。
- 岩石风暴调整碎石体积、升起过程与加速旋转。珊歌的普攻光弹沿飞行方向拉伸，命中亮点延后到光弹到达时。
- 地图道路转角改成圆滑采样，战斗路径、道路绘制、道路摆放排除共用同一组点。树木、礁石周围不能摆放伙伴。
- 岸壁按几何面计算法线；棕榈从直片改为弯干和弧形叶；灯塔增加腰线、门及台阶。近看镜头更靠近角色。

## 源文件

- `game/art-source/sculpted-review/build_review.py`：可重建角色的网格、材质、权重与九组动画。
- `game/art-source/sculpted-review/finish_pass.py`：接触遮蔽、落脚约束、眼睑和袍服。
- 各角色目录的 `.blend` 保留分件编辑结构，`.glb` 供交换；Cocos 运行时加载 `assets/resources/models-sculpted/` 下的 FBX。
- `game/assets/scripts/view/SkeletalReviewScreen.ts`：运行时材质、真实场景、动作播放、技能表现。

接触阴影在生成脚本中重新烘焙到运行网格；源 `.blend` 保存的是烘焙前的可编辑分件。没有添加第三方角色或特效包。

## 验证记录

输出目录：`output/sculpted-polish-20260915/`。

- `FBX-validation.json`：在新的 Blender 进程独立回导三份运行 FBX。每个顶点权重归一、最多两骨骼影响、九段动画均实际驱动网格；接触阴影顶点色保留。
- 回导后的岩盾、珊歌脚骨在待机、攻击、施法、受击和入场的采样中位移不超过 0.00002 米。这个检查验证定点动作的约束，不等于所有转向和移动已经没有滑步。
- `stone-lid-open/closed.png`、`crystal-lid-open/closed.png`：由回导的运行 FBX 渲染的眼睑特写，不是绘制的效果图。
- `targeted-tests.log`：32 项针对性回归通过，覆盖原首页入口、验收入口的存档隔离、道路与障碍物排除，以及真实伤害、主动和专精触发。
- `typecheck.log`：Cocos TypeScript 检查通过。
- `build-final.log`：完整 Cocos 构建与构建产物核心回归记录。
- 最终构建在 7475 页面实际载入，观察到怪物沿新道路前进、近战交锋、击败与漏怪扣除守护值；一局运行至 76 秒正常结束。浏览器错误/警告检查为空。`actual-battle.png` 记录重开后第 7 秒的实际画面。
- 近看与 180° 转身检查中，背壳、手臂与水晶保持三维遮挡；岩石风暴慢放可观察到碎石升起和空间光带。此项只证明当前效果可用，仍保留特效细节精修工作。

## 后续制作的边界

本轮是技术样板向可用美术资产前进的一步。手指、面部结构、布料褶皱、材质层次和连贯的表演还需要专门精修；当前技能也是可继续编辑的初版。不能把有骨骼、能转身等同于商业三维动作质量。

后续按同一标准完善这两只角色的连续实战表现，再扩展叶灵、阳光、潮行和敌人，并接回正式关卡。上线前仍需要真机帧率、内存、资源加载与不同画质档位的专项验证。
