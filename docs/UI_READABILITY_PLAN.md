# 手机横屏 UI 可读性实施方案

日期：2026-09-08。范围：GameEntry 的收藏、详情、出战选择，BattleScreen 的阵容、招募、合成，以及 IslandUI.roleMark。**本轮只读生产代码与现有 PNG，并写本文件；未启动浏览器、Cocos、Blender，未改生产代码或美术。**

## 结论与证据边界

需要减少同屏密度并调整布局，不能只把头像和字号乘一个系数。现有收藏 3 列可以保留；出战/合成 5×2 卡片、战斗十张横排和详情四列混排必须重排。以手机能看清、点准为默认布局，桌面窄窗沿用这套布局并显示窗口提示。

证据来自当前代码中的坐标、主线程提供的 689×864 实测尺寸，以及主线程本轮 [220715 观察记录](C:/Users/Administrator/Documents/ChatGPT/gowaygui/docs/reports/home-ui-220715-observation.md)。该记录实际查看了收藏、水晶详情与第五关；没有把本方案的估算称为新的截图或手机触摸实测。本轮未拿到可独立查看的当前流程截图，故这是一份代码和实测尺寸驱动的实施方案，不是完成了现场截图验收的视觉审计。旧摄影棚截图不作为当前五龟页面证据。

只使用现有五张 384×384 RGBA 头像、图标图集和面板素材。PNG 只读 alpha 检查表明：五张实际可见主体宽均约 340/384=88.5%，高度约 66.7%～79.2%。所以头像节点 48 CSS px 不等于主体宽 48 CSS px；不能用贴图分辨率 384 证明屏幕上看得清。

## 1. 手机与窄桌面的关键区别

当前设计坐标为 1280×720，SHOW_ALL 的屏幕比例为 `s=min(W/1280,H/720)`，以下不含系统安全区。

| 场景 | s | 实际游戏画布 | 留白 | 意义 |
|---|---:|---|---|---|
| 手机横屏 844×390 | 0.5417 | 693.3×390 CSS px | 左右各约 75.3 px | 游戏高度限制缩放，横屏仍很小 |
| IAB 窄桌面 689×864 | 0.5383 | 689×387.6 CSS px | 上下各约 238.2 px | 与上述手机的游戏内容大小几乎相同 |
| 桌面 1280×720 | 1 | 1280×720 CSS px | 无 | 大桌面的清晰不能代替手机验收 |

例如设计字号 18 在真实手机横屏约为 9.75 CSS px；当前 36 高按钮只有 19.5 CSS px。即使将手机左右留白全部用来铺满，横向拉伸也不会增加纵向文字与触摸高度，还会损坏头像比例。

- **手机横屏**：采用下文的低密度布局；后续平台适配再接实际安全区，不依赖浏览器全屏或旋转提示解决小按钮。
- **窄桌面竖窗**：使用同一可读布局。提示“拉宽窗口，海岛视野更完整”，放在游戏画布外的空白区，不遮挡操作，也不把桌面用户当作手机要求旋转。当前约 388 px 的游戏高度仍可以验证尺寸。
- **手机竖屏**：提示转横屏；不把 16:9 游戏缩到竖屏宽度后宣布适配通过。第一版不需要再开发一整套竖版玩法页面。
- 第一批验收以安全区内可用尺寸至少 640×360 CSS px 为基准；低于此范围需另做更紧凑分页或明确提示，不继续任由 SHRINK 把关键内容压小。

### 安全区与坐标转换

这里的所有新坐标均是 **居中的 1280×720 UI 局部设计坐标，Y 向上**，不是 CSS 坐标。对手机安全区应先计算可用矩形，再将整套 UI 等比居中放入这个矩形。844×390 若仅扣 21 px 底部安全区，缩放约为 0.5125，88 高按钮仍约 45.1 CSS px。

不要只把底栏单独上移而保留招募/合成条原位，这会让两条相撞。若实现为 UI 根节点缩放/平移，必须同时修正 BattleScreen 的世界位置投影和揭晓擦拭坐标：统一转换到该 UI 根的局部空间，不能继续硬减 640/360。3D 相机可以保持原视野；此次方案不要求重做五张地图或改变战斗路线。

还有两个确定的布局原因：

1. `IslandUI.roleMark` 的 `size` 是半边长，实际节点边长为 `size*2`。应在新调用处使用明确的 `portraitSide`，传入 `portraitSide/2`；不要改这个参数含义后让旧调用全部翻倍。
2. `IslandUI.label` 默认所有文字 `SHRINK` 且允许换行。只把字号从 16 改到 30，在旧框里仍会被静默缩回去。正文需要足够宽高，长名字要显式截断并在详情展示完整名，不允许关键成本和数量靠自动缩字兜底。

BattleScreen 顶部也有实际矩形重叠：关卡名中心 -489、宽 226，右边为 -376；守护文字中心 -334、宽 180，左边为 -424，同一行相交 48 个设计单位。下文同时给出一个不重叠的顶栏分配。

## 8. 落地顺序与验收
