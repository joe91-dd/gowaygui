# 免费商用音乐与音效（2026-09-16）

当前共享源码使用 3 首音乐、39 个音效，全部来自明确标注 **CC0 1.0** 的素材。无需购买、订阅或强制署名；仍保留作者信息致谢。许可说明见 [Creative Commons CC0](https://creativecommons.org/publicdomain/zero/1.0/)。2026-09-17 先补齐至 33 个交互音效，随后其他窗口扩展了面板展开、抽取提示、三阶段祈愿和首领施法共 6 个音效；本窗口统一复核 42 个资源与授权通过，等待主窗口统一构建。原交互说明见 [交互音效补齐](AUDIO_FEEDBACK_20260917.md)。

## 音效

全部取自 Kenney 的 [Interface Sounds](https://kenney.nl/assets/interface-sounds)、[Impact Sounds](https://kenney.nl/assets/impact-sounds)、[RPG Audio](https://kenney.nl/assets/rpg-audio)、[Music Jingles](https://kenney.nl/assets/music-jingles)，四包均标注 CC0，下载包内的 `License.txt` 一同保留。

| 事件 | 反馈 |
| --- | --- |
| 按钮、擦泡泡、破泡泡 | 短点击、摩擦、拨弦气泡 |
| 普攻 | 近战碰撞、远程挥击、晶体法术，低音量且限频 |
| 职业技能（含自动施法） | 岩盾：矿石重击；尖刺：连续掠射；晶炮：玻璃爆裂；叶灵：上行拨弦；泡泡：连续弹跳 |
| 护盾、暴击、治疗、复活 | 各自独立提示；无效果的零伤害/零治疗事件不发声 |
| 波次开始、首领出现、核心受损 | 确认短句、低钟声、重碰撞 |
| 合成确认提交 | 能量上升；提交失败不响 |
| 擦泡泡揭晓合成结果 | 独立完成乐句；稀有结果使用稀有乐句 |
| 购买、学习技能、收录、领取 | 金币、翻书与确认、收集提示 |
| 胜利、失败 | 独立结果提示；世界首领按伤害结算播放领取声 |

音效在成功事件后触发，不因页面重绘重复。普通关卡、本地挑战、联机副本、竞技场演练、世界首领共用 `IslandAudio.battleEvents`。六路音效上限、按事件限频，技能和结果声音优先于普通攻击。音乐/音效音量继续使用原有独立设置，首次用户点击解锁播放，切后台停止音效并保存音乐位置。

## 可复核来源与制作

- `game/audio-source/cc0-20260916/`：原始压缩包、原始音乐、作者来源页快照、Kenney 包内许可。
- `music-a/`：已选择 A 套的三首原曲与作品页；`music-selection.json` 固定场景映射与来源校验和，后续重建默认使用 A 套。
- `before-music-a/`：本次选曲前的三首运行文件与完整来源清单。
- `manifest.json`：每个运行文件的来源、作者、许可、SHA-256、时长、峰值；分层音效逐层记录输入文件、偏移、播放速率和增益。
- `build_audio.py`：可复现转换脚本。音乐保留立体声；音效修剪静音边缘、5ms 淡入淡出、峰值约 -12 dBFS，进入游戏后再按事件减小增益。
- `previous-runtime/`：替换前运行素材备份。以前的原创谱面、母带、分轨仍在 `game/audio-source`，不再作为本轮运行素材的来源。
- `output/audio-cc0-review.html`：本轮独立试听页，含背景音乐切换与叠加技能、合成音效。

自动测试及解码测量验证播放逻辑、资源完整性和无削波，不代表已经完成人耳试听或手机外放审美验收。
