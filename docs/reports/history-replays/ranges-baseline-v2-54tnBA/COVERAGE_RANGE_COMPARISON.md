## 结果解释与候选取舍

1. 本次共 752 个真实服务波次；全部完成检查点重启一致性和重复结算断言。第 5 关“通关”表示核心未被摧毁，不能直接等同于击败首领：baseline 首领击败 6/8、漏过 2/8；候选击败 8/8、漏过 0/8。
2. 候选第四关核心平均 17.000→18.875，末波友军血量仅小幅变化；第五关末波友军血量 46.30%→87.17%。这不是可以忽略的强度变化，后续需评价后期难度与治疗职业的实际价值。不能为保留原有压力而默认接受原治疗覆盖失效。
3. 第五关有倒地波数仍是 5/96→5/96，候选也并非全员安全；各个体与波次结果应连同整体血量一起看。范围扩大也不保证每个种子更快，完整配对区间已经列出；本报告没有把该差异归因于某个未经隔离证明的单一技能。
4. 数值候选确实能补第四关的几何缺口：法师/泡泡 4.6 大于原最早拦截点距离 4.586844，但基础余量仅 .013156；叶子基础 4.5、鼓劲/分担 4.5 大于 2↔4、3↔4 的 4.472136。叶子初始远望会达到 4.8。位置 4 到位置 1 仍 7.211，不会变成全场普通治疗。石头 1.2 不变，远程格也未强制变近战格。
5. 建议把该组值保留为下一轮运行候选，结合主线程真实阵型与关键首领压力验证后再定生产值。固定模拟器并未搜索最佳摆位，不能据此宣布五职业阵型和平衡最终完成。本次未采纳或实施候选。

## 局限与复现

- 8 个固定种子用于成对回归，不是玩家群体胜率。不能把固定阵型全过等同于每种开局、排位或合成决策都合理。
- 末波友军血量不能说明整波最低血线；本次没有侵入生产 tick 统计。完整 JSON 保留每波五只龟的生命、射程、普攻次数与技能激活，便于避免只看核心血量。
- 准备时间只包含模拟器固定值，不包含资源加载、界面、停顿、玩家思考和收录等时间。
- 此处只比较新波次 balanceVersion 2；旧 combat 的范围保留/下一波切换由专门兼容测试承担。
- 本次不改变胜负、奖励、命令、随机数或存档实现；所有服务存档仅在进程 MemoryStorage。
