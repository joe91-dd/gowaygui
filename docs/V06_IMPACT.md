# V0.6 影响范围与实施约定

依据：用户亲自试玩后提交的 [V0.6 增量指令](../output/哥喂龟V0.6核心玩法增量修改指令.md)。本文件记录实施解释，不覆盖原文；V0.6 与旧设计直接冲突时采用 V0.6。

## A：完全保留

现有 Cocos 3.8.8 工程、五龟及六动作、角色材质、头像、海岛、七种敌人及首领、UI 组件与风格、音效和音频系统；30 技能与职业兼容、十二技能全部生效、三资质和成长及培养费用；正式合成概率算法；确定性战斗、原子存档、重复提交保护、平台边界。用户已基本认可整体美术，本轮不新制大批资产、音乐或无关包装。

## B：适配修改

- 新开局记录规则版本和模式；最多五只永久龟直接布阵，关卡另外生成五个固定备战槽。备战个体有独立槽号和免费刷新锁，不混同永久收藏的资产锁。
- 每个非末波胜利刷新未锁定备战个体、补空槽；锁定个体保留。末波直接结算现存槽位，不在通关后额外生成一轮新龟，保留少于十只的真实带回结果。
- 备战合成两只本局个体直接消耗、固定新结果；换下场的个体本局淘汰，不再成为可出战替补。永久收藏原件始终独立，不因换下或本局失败删除。
- 成功通关自动带回能容纳的有效新个体，满仓剩余个体保留在待整理列表；不自动删除已有龟，也不复制原永久个体。失败/主动结束不新增通关龟奖励。新一局开始前处理待带回项。
- 收藏容量五十，品质排序、改名、明确确认后放弃个体；旧档若已超五十不删资产，暂停新增直到整理到容量内。
- 局外合成固定 C 并保存，揭晓后 A/B/C 留一，另两只消耗；未完成选择不能继续培养、再合成或开局，重启继续同一次结果。旧历史数据保留，但新版流程不再写入历史。
- 技能书继续随机覆盖一项、不增加技能数量；消耗与结果先保存，再使用共同擦泡泡组件揭晓。重启不重新抽取。
- 品质分数仅为界面参考，权重/阈值配置化，不参与任何战斗属性或合成概率。
- 同一战斗时钟按 1X/2X 推进逻辑、冷却、计时和表现；奖励仍按唯一波次结算。
- 无尽当前只有旧设计和未批准候选，尚无完成的生产模式。复用同一引擎和现有海湾；参考旧五波/十波节点，按 V0.6 配置五格随机奖励选择、差异化书池、阶段礼包和失败保留收益。初值明确标注 Gameplay Prototype，首轮可玩后停止调参。

## C：只替代直接冲突内容

新版关卡停用逐波一次三选一招募、第一只先上场、旧有限合成窗口、永久来源确认收录转历史、战场龟可反复退回替补重上。新关卡使用五槽刷新和通关带回；局外使用三选一留一。旧进行中局次仍保留原版本恢复路径，不把中途存档强改成 V0.6。历史入口隐藏，兼容代码与原文不删除。

原 2026-09-09 无尽候选表的等概率技能书、旧转历史规则和招募方案已被 V0.6 替代，不能直接接入。V0.6 已授权首轮配置值；此前缺失配置的确认问题不再作为实施阻塞。

## 检查点与停止条件

1. 先保存当前可回滚检查点，再实现规则版本、备战槽、带回、收藏与局外合成事务。
2. 接入无尽波次、奖励账本、不同书权重、阶段礼包和永久培养；不注入测试资源。
3. 用现有 UI 接线拖动、刷新、品质、整理、重命名、共同擦泡泡与速度切换。
4. 验证资产不重复/不丢失、两个不可逆步骤恢复、换下不可重上、刷新锁、五十容量、倍速一致、奖励与书的真实获得和使用、死亡保存与第二局。
5. 实际构建试玩；仅做适应五龟开局的一轮压力配置，记录主观 P2/P3，交付可玩版后停止扩展，等待用户体验判断。

无尽、公开榜/PVP/租借、平台适配、完整音乐和其他未冲突路线图继续保留；本轮暂停不代表取消。现有 LOD 独立候选不晋升、不继续打磨。
