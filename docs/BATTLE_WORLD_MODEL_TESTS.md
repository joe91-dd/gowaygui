## 暂停与长帧修复

原先 `BattleScreen.update` 在 paused/modal 时返回，模型计时停止，但骨骼仍由 Cocos 的全局动画管理器推进。本机 Cocos 3.8.8 `animation-manager.ts:81–97` 与 `animation-component.ts:233–244` 确认必须单独暂停/恢复动画。

`BattleWorld.setPaused` 现在立即暂停或恢复所有现有角色骨骼；统一的 `play` 在启动 clip 后重施暂停，覆盖迟到 Prefab、暂停期间重新同步以及新角色。恢复调用 `resume` 保留动作相位，不重播。暂停时世界表现计时也不推进。

`BattleScreen.setPauseState` 统一手动暂停、存档恢复、hide/show、伙伴/合成/比较/揭晓/结算弹窗、异常、继续和放弃路径。关闭普通弹窗不解除手动暂停；从后台返回仍需点击继续；销毁后的可见性回调无效。测试通过实际按钮回调和真实战斗规则确认即时暂停与规则 tick 不推进。

真实模型的 actionTime/deathTime 改用与引擎同源的完整非负 dt；程序化插值与特效仍保留 0.1 秒上限。新死亡首帧仍不消耗过去时间。测试覆盖 0.5 秒 + 0.34 秒长帧完成退场，以及暂停跨数秒后只按未暂停时间完成。
