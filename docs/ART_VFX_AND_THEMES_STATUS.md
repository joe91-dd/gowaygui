# 美术、技能特效与地图主题交付清单

更新时间：2026-09-20

## 角色与怪物表现

- 五只基础龟龟与五只 10 技能进阶龟龟使用独立全身模型；进阶体型按战斗占地放大一档。
- 10 技能头像、全身展示图、战斗模型和进阶武器使用同一角色映射。
- 进阶武器在 `prepareBattleRig` 之后挂到手部 socket，跟随转向、攻击、施法和退场动作。
- 敌方 G1 目录已接入普通怪、精英和首领模型；模型导入前做了法线/拓扑修复和材质检查。
- 战斗角色动作覆盖 idle、walk、turn、attack、skill、hit、rest、exit；缺少原生骨骼动作的模型使用统一的战斗姿态驱动。

## 已接入的技能与战斗特效

| 类型 | 交互/表现 |
|---|---|
| 岩盾 | 岩石风暴、范围环、岩块碎片、护甲强化光环 |
| 射手 | 穿甲弹、箭矢拖尾、箭雨落点、命中火花 |
| 法师 | 海霜风暴、冰晶碎片、冻结/碎冰脉冲、法术拖尾 |
| 治疗 | 治疗波、净化光环、护盾光圈、复活脉冲 |
| 控制/召唤 | 潮灵召唤、落地冲击、定身/破甲/虚弱反馈 |
| 通用 | 暴击星芒、反伤/弹射连线、受击火花、死亡碎片、入场和胜利光效 |
| 首领 | 火焰弹、吸取、集结、迫击弹、范围预警环、首领核心脉冲 |

手动技能进入瞄准后，战斗逻辑暂时冻结；选中目标、拖拽释放或取消后自动恢复。换位与集火沿用同一输入冻结窗口。

## 地图主题

战役每 5 关更换主题和路线：晴湾海岸、珊瑚浅滩、潮汐湿地、古树海岛、白帆礁群、月湾遗迹、风暴海峡、晶石深湾、沉船群岛、海心王座。副本、竞技、无尽和世界首领使用独立主题入口与路线；同一主题内仍保留不同路线、站位和障碍组合。
