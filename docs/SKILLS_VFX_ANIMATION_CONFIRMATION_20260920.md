### 4. 解决“飘着”和“不明显”的运行验收

1. 每个模型每个动作按 30 fps 采样脚底；地面单位脚底误差控制在 ±0.02，不能出现持续离地。
2. 根骨只负责身体重心和朝向；移动路径由战斗状态驱动，不能把整只模型无条件上下抬升。
3. 地面单位的 walk/run 必须有交替支撑脚、步幅和身体倾斜；浮空只允许标记为飞行的身份。
4. 转向使用脚底锁定的 turnL/turnR 或原地混合，转身期间不横向滑步。
5. 攻击/施法动作写入 `windup / release / recover` 标记；特效、伤害事件和声音都绑定 release 帧。
6. 轻受击不打断攻击收势；重击、眩晕、蛛网才进入受控动作。
7. 死亡使用 `death`，退场使用 `exit`；死后先完成倒地/消散，再移除节点。
8. 每个首领的预警、施法、命中、受击、死亡至少各录一段实机检查；不能只用静态截图验收。
