# 游戏内特效修订记录 · 2026-09-20

此前三张预览板属于示意图，不是游戏截图。旧 vfx-coverage.json 只搜索了字符串，不能证明效果完整，不能作为验收通过依据。此前对冰冠、锁定眼、沉睡 Z 气泡等描述超出了实际实现，本记录撤回这些完成声明。

本轮实现位于 G1BattleEffects.ts、BattleWorld.ts 和 g1-particle.effect：

- 新增 4×3 彩色主体贴图 models-g1/fx/spell-volumes-v1.png：冰晶、火焰、水浪、治疗、漩涡、蛛网、护盾、岩尘、风刃、暗能量、命中、藤蔓。它是绘制资源，不是实机截图。
- 主体贴图与三维碎片、拖尾和序列帧叠加；火雨分飞行与延迟爆发，穿透箭沿施法者到目标飞行。
- 护盾、蛛网、缠绕、破浪使用各自主体；治疗、召唤、岩石风暴、冰风暴不再仅依靠细线光圈。
- 修正重生按 skillId 识别、追击按 effect 识别、鼓舞和净化在受益者位置显示；避免首领蓄力动画被通用施法动画覆盖。
- 波次切换清理临时特效。状态变化补充破甲、减抗、虚弱、沉睡反馈。
- 本地特效检视参数：?preview=all-maps&map=0&vfx=1&qa=1，36 个选项，可播放和定格，直接使用 BattleWorld 同一渲染器，不改变战斗规则或正式存档。

检视入口展示的是同一渲染器的受控播放，不能替代每一种技能的战斗触发测试。变形和沉睡目前使用状态爆发反馈，没有新增羊模型或 Z 字模型。
