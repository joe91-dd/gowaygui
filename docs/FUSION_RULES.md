# 单机序章合成配置 island 0.1

实现依据为讨论稿 v0.5，局内合成不扣永久金币。此版本完整补齐原稿未给出的配对数量分布，属于可测试配置而非最终上线爆率。

1. 同职业结果为该职业；异职业两分支各 50%。先按职业去掉无效技能并去重，数量不超过合法池与十二项上限。
2. 至少十二种兼容技能才有十二技能结果。单次十二技能概率按较少技能亲本：1–4 为 0.001%，5 为 0.005%，6 为 0.01%，7 为 0.02%，8 为 0.05%，9 为 0.08%，10–12 为 0.1%。不折叠不可能的十二结果到十一或最大技能数。
3. 十一技能尾率按较少技能亲本分别为 0.01%、0.05%、0.2%、0.6%、1.95%、3.5%、6%（分组与十二表相同），同样需至少十一兼容技能。
4. 同职业八加八且池足够时严格使用原稿 4–12 技能概率：3%、8%、16%、27%、28%、12%、4%、1.95%、0.05%。池不足时保持可达顶端尾率，其余概率按低段原权重重新归一，未直接抬高最高结果。
5. 其他输入对低段（最多十技能）使用中心为亲本平均数量减 0.45、标准差 1.35 的离散高斯权重，最低数量为亲本平均数量一半向下取整且至少一，截到合法池。剩余质量分配到低段。这是透明的试验补齐规则，需要长期择优仿真和用户试玩后再校准。
6. 具体技能从合法池均匀无放回抽取；资质成长使用天生值均值加公开中心化离散扰动，培养不遗传。资质扰动 -8/-5/-2/0/+2/+5/+8 对应 3/10/20/34/20/10/3%；成长百分位扰动 -3/-2/-1/0/+1/+2/+3 对应5/15/20/20/20/15/5%。
7. 生成后保存固定结果和随机状态，擦拭、跳过和重启均不重抽。用户选择收录才改变永久来源。PRNG 为本地确定性实现，不宣称防篡改。
